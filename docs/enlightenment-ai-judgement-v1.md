# 啟蒙層 AI 綜合判讀規格 v1

版本：`enlightenment-ai-judgement-v1`
建立日期：2026-09-05
用途：日 K 選股名單的結構判讀、進場觸發與因果回測規格

## 1. 定位

本規格把啟蒙課程用於「既有選股策略產生候選股之後」的第二層分析。它不是新的選股器，也不是把課程簡化成固定數值公式。

核心分工：

- 程式負責資料取得、除權息處理、指標計算、可見日期切斷、狀態保存、成交模擬及績效計算。
- AI 負責選擇定錨、判斷級數、太極複製／修正、道氏方向與防線、四象限、左右階段、位階及是否觸發。
- 每個 AI 結論都必須附可核對的日期、價格結構、主要解讀、替代解讀與失效條件。

本規格採三種標記，避免混淆來源：

- `COURSE_SOURCE（課程明確內容）`：整理稿可直接支持的原則。
- `RESEARCH_EXTENSION（本研究延伸）`：把課程從一分 K 延伸到股票日 K 的設計。
- `BACKTEST_PARAMETER（回測參數）`：為了可重現回測而暫定、必須另行驗證的數值。

## 2. 課程依據

主要依據：

- `course_knowledge_base/啟蒙交易班/整理成果/啟蒙交易班_課程整理.md`
- `course_knowledge_base/啟蒙交易班/整理成果/四象限戰法強化_完整課程整理.md`
- `course_knowledge_base/戰法C班/整理成果/戰法C班_完整課程整理.md`
- `course_knowledge_base/道氏三兄弟/整理成果/道氏三兄弟_完整課程整理.md`
- `course_knowledge_base/Elson股票班/整理成果/Elson股票班_完整課程整理.md`

課程共同核心為：先定錨，再判方向、級數與狀態；策略必須同時包含進場、出場、部位與加碼；失效後不可更換週期或戰法替持倉找理由。

## 3. 不可違反的因果規則

以下為硬規則，不交由 AI 自由裁量：

1. 判讀日只能使用該日收盤以前已知的資料。
2. 日 K 收盤才成立的 `TRIGGERED（已觸發進場）`，下一交易日開盤才模擬成交；不再增加第二次確認。
3. 當日最低點、最高點及樞紐只有在當時可確認時才能使用，不可用後續 K 棒事後把最低點當成當日買點。
4. 同一股票、同一天、同一方向的多個訊號若描述同一段行情，只建立一個部位，其他訊號保存為證據標籤。
5. 第一個實際成交部位永遠是 `MOTHER（母單）`；錯過先前理論買點後的首次成交仍是母單。
6. 虧損中的持倉禁止加碼。
7. 每筆計畫必須指出結構失效條件；無法指出時不得觸發。
8. 訊號計算使用公司行動還原後的技術價格；現金損益使用實際成交價格並另計股利、權值與交易成本。
9. 小級／部位防線停損只結束該次交易回合；大級結構仍有效時，可以等待新的獨立小結構再次進場。
10. 再次進場不得沿用已失效的舊觸發或舊防線，必須建立新的母單、失效點與交易回合編號。

## 4. 資料充分性

### 4.1 標準資料量

`BACKTEST_PARAMETER（回測參數）`

- 首次被選入監控前，目標取得至少 750 個有效交易日。
- 最前面至少 200 根只作為 MA／EMA／MACD 暖機。
- 暖機後應保留至少 500 根供結構與世代判讀。
- 固定日期回測時，建議統一從 2023-01-01 或更早取得資料，再按交易日裁切。

### 4.2 結構最低要求

MACD 21/55/55 是波段切分的輔助證據，不是唯一的定錨判定器。最低希望能看到：

```text
負向區間有效低點 L0
→ 正向區間有效高點 H1
→ 下一負向區間有效低點 L1
→ 當前發展段
```

這代表至少有一個完整的「推進＋修正」。最好有兩個完整循環，才能比較父代與後代。

交叉日不等於結構高低點；AI 應找正負區間中的有效高低點，再檢查乾淨度、幅度、斜率、破壞性、道氏防線與長均線關係。

資料不足時：

- 標記 `DATA_INSUFFICIENT（資料不足）`。
- 不做大定錨複製的高信心判斷。
- 新上市或缺乏完整循環者，可單獨評估 `FRESH_Q1_EXPANSION（新生定錨直接擴張）`，但必須與完整歷史樣本分組統計。

## 5. AI 定錨程序

### 5.1 先列候選，不直接宣布答案

AI 至少列出一個主要定錨與零至兩個替代定錨。每個候選都要記錄：

- 起訖日期與方向。
- 起訖價格、幅度、歷時與相對 ATR。
- 內部轉折、影線、斜率及量價特徵。
- 是否突破重要區間、箱型、長均線或大小級道氏防線。
- 原定錨失效點。

### 5.2 有效定錨的綜合判斷

`COURSE_SOURCE（課程明確內容）`

- 乾淨：影線與內部樞紐較少，方向一致。
- 有肉：幅度足以成為可操作推進，但不是已耗盡大部分空間。
- 有破壞性：突破重要高低點、區間或道氏防線。
- 可追溯：能指出起點、終點、方向、級數及失效。

`RESEARCH_EXTENSION（本研究延伸）`

- 股票日 K 可用 MACD 21/55/55 正負週期協助切分候選波段。
- 105MA、144MA 的觸及、收復或長期斜率只作為大結構證據，不能單獨觸發。
- 定錨起點可以早於 MACD 黃金交叉；交叉常是後續確認，而非起點本身。

### 5.3 大、小兩個工作級數

一般只維持兩個工作級數：

- 大級：決定主要方向、潛在空間與母單是否可成為趨勢部位。
- 小級：決定當下控制權、實際觸發與加碼／減碼節奏。

大、小級打架時不強迫投票。AI 要說明暫時由誰控制、另一級造成什麼風險，以及哪個事件會使控制權改變。

## 6. 太極、世代與位階

AI 必須把每段標示為：

- `ANCHOR（定錨／第 1 段）`
- `CORRECTION（修正）`
- `REPLICATION（複製）`
- `RESET（重置／反向定錨）`
- `COPY_TO_CORRECTION（複製轉修正）`

世代使用：

- `ANCHOR_LEG_1（定錨段）`
- `COPY_LEG_3（第一代複製／第三段）`
- `COPY_LEG_5（第二代複製／第五段）`
- `LATER_GENERATION（更後代）`

判斷後代品質時，不只比較點數，還要比較：

- 幅度與修正比例。
- 完成時間與斜率。
- 乾淨度與內部轉折。
- 是否持續突破父代重要高低點。
- 四象限是否由 Q4 重新轉成 Q1，或由 Q1 衰退。

第五段、第三次攻擊或更後代不自動禁止交易，但必須降級，並明確說明剩餘空間、追價與複製失敗風險。

## 7. 道氏、樞紐與左右戰法

### 7.1 道氏狀態

大、小級分別保存：

- `BULL（多頭）`
- `BEAR（空頭）`
- `TRANSITION（轉換中）`
- `UNDEFINED（未定義）`

每條防線必須保存級數、價位、來源樞紐、建立日期及失效日期。小級防線被破，不等於大級定錨自動失效。

### 7.2 左右戰法只用於反轉候選

- `LL（左左）`：大防線未破，末段猜測；價格較好、勝率較低。
- `LR（左右）`：小級慣性翻向，但大防線仍未破。
- `RL（右左）`：大防線突破後第一次有效拉回。
- `RR（右右）`：右側拉回後再次延續突破。
- `DIRECT_TO_RIGHT（直接進入右側）`：快速 V 轉穿越防線，未形成清楚左側階段。

左右階段是結構狀態，不代表四個位置一定全部成交。第一個實際成交仍為母單。

## 8. 四種主要情境路由

這些是可轉換的狀態，不是股票的永久分類，也不是四個獨立投票器。

### 8.1 `MACRO_COPY_RESONANCE（大定錨複製共振）`

適用於台半、百容式結構：

1. 已有有效大級多頭定錨。
2. 大修正未明確破壞原錨或已完成合理的級數重估。
3. 小級反向定錨向上突破修正段道氏防線。
4. 小級拉回守住後重新轉強，或大小級對下一段策略要求一致。

有效觸發不是「碰到均線」，而是修正結束後的可觀測轉強事件。

### 8.2 `BEAR_REVERSAL_LEFT_RIGHT（空頭末端左右反轉）`

適用於原先沒有多頭大結構的空轉多：

1. 原空頭可能已在第三次攻擊、第五波、複製衰退或末段加速。
2. 依 LL／LR／RL／RR 追蹤反轉建立程度。
3. 小級先翻多時仍承認大級空頭壓力。
4. 穿越大級防線後，才升級為較高確認度反轉。

### 8.3 `FRESH_Q1_EXPANSION（新生定錨直接擴張）`

適用於盤整後或空頭反轉後直接形成強勢小結構：

1. 出現乾淨、有肉、具破壞性的新生向上定錨。
2. 大級可能仍為空或未定義，但新錨持續創高、修正少、動能擴張。
3. 仍在發動初期；若已多根加速、離防線太遠則不追。
4. 進場後應快速延續，否則使用時間／動能失效退出。

康舒示範此情境可以由 `BEAR_REVERSAL_LEFT_RIGHT` 轉入本情境，再於完成推進與修正後轉入 `MACRO_COPY_RESONANCE`。

### 8.4 `MATURE_TREND_PULLBACK（長多慣性拉回再發動）`

適用於長期向上、具有個股均線慣性的股票：

1. 大型態／長期價格面仍向上。
2. 回到歷史慣用均線、105MA／144MA 或大結構區域。
3. 不在均線上預先猜反彈；等待止跌、收復、勾起或小道氏翻多。
4. 若大級 Q4 與小級 Q2 雖名稱不同，但對下一段都要求向上，可視為策略共振。

## 9. 排除與不交易

以下通常輸出 `REJECTED（不合格）` 或繼續 `WATCHING（監控中）`：

- Q3 低趨勢、低波動且沒有足夠空間。
- 無法指出有效定錨或結構失效點。
- 大、小級劇本互相衝突且沒有清楚控制權。
- 距離最近可用防線過遠，風險報酬已顯著惡化。
- 後代持續縮短、變慢、變亂，或複製失敗後仍追價。
- 爆量加速發生於明顯末代，且沒有新的風險界線。
- 訊號只是單一均線、MACD 或量能事件，缺乏結構支持。

AI 不得因知道後來上漲而把上述缺陷忽略。

## 10. 狀態與觸發語意

| 狀態 | 定義 |
|---|---|
| `WATCHING（監控中）` | 尚未建立足夠清楚的結構 |
| `STRUCTURE_MAPPED（結構已辨識）` | 已能說明主要與替代結構，但沒有可執行計畫 |
| `ARMED（已建立進場計畫）` | 已知等待事件、觸發條件及失效點，事件尚未成立 |
| `TRIGGERED（已觸發進場）` | 當日收盤已完成進場條件；下一交易日開盤執行，不需再確認一次 |
| `REJECTED（不合格）` | 當前機會不符合結構、位階或可執行風險 |
| `INVALIDATED（結構失效）` | 原計畫或原錨已遭破壞，必須重置 |
| `DATA_INSUFFICIENT（資料不足）` | 無法支撐所需級數判讀 |
| `OPEN（持有中）` | 已成交且尚未完全出場 |
| `ADD_ARMED（已建立加碼計畫）` | 持倉已有市場證明，正在等待下一個獨立加碼事件 |
| `EXIT_WARNING（出場警戒）` | 出現衰退或末代警告，尚未完成強制出場條件 |
| `STOPPED（停損出場）` | 本次交易回合因小級或部位防線失效而結束；不代表大級結構必然失效 |
| `REENTRY_WATCHING（再進場監控中）` | 已停損但大級結構仍有效，等待新的獨立小結構觸發 |
| `CAMPAIGN_INVALIDATED（大結構交易週期失效）` | 大級定錨或大級防線已遭破壞；停止沿用本次大結構並移出本次監控資格 |
| `REMOVED_FROM_WATCHLIST（已移出監控）` | 大結構交易週期失效；必須等上游選股策略再次選入才可重新啟用啟蒙層 |
| `CLOSED（交易已結束）` | 已完全出場 |

## 11. 母單、加碼與同日去重

第一階段先凍結進場，不同時最佳化部位。後續比較：

1. `MOTHER_ONLY_10K（母單一筆一萬元）`
2. `MOTHER_PLUS_2（母單加兩次）`
3. `MOTHER_PLUS_3（母單加三次）`

一般課程以母單加兩次為常見完整計畫；左右戰法另有四階段部位。兩者必須分開回測，不混成老師唯一指定做法。

加碼必須同時符合：

- 原持倉按當日收盤已有獲利。
- 出現不同日期、獨立的新結構證明。
- 防線已上移或新的加碼單有自己的結構失效點。
- 不是同日多個證據標籤重複計數。
- 不是 Q3、末代衰退或大小級嚴重打架。

### 11.1 停損後再次進場

每一個大級定錨及其後代構成一個 `campaign（大結構交易週期）`；同一個 campaign 內可以有多個彼此獨立的 `trade episode（交易回合）`。

小級或部位防線停損後：

1. 該 episode 標記 `STOPPED（停損出場）`，損益獨立結算。
2. AI 重新檢查大級定錨與大級道氏防線。
3. 大級仍有效時轉入 `REENTRY_WATCHING（再進場監控中）`。
4. 必須先形成新的修正、樞紐或小級反向定錨，再依小道氏翻多、Q4 轉 Q1、RL／RR 或其他獨立轉強事件重新觸發。
5. 再次觸發建立新的 `MOTHER（母單）`、新的 episode 編號及新的失效點；不是加碼，也不得把舊觸發重複使用。
6. 若大級定錨或大級防線也失效，標記 `CAMPAIGN_INVALIDATED（大結構交易週期失效）`，接著轉為 `REMOVED_FROM_WATCHLIST（已移出監控）`；即使日後自行形成新定錨，也必須等上游選股策略再次選入，不能由啟蒙層自行恢復監控。

初期 AI 小測試不設定任意的固定等待天數，也不以停損次數直接禁止再進；但必須記錄連續失敗次數。相同大結構若反覆失敗且沒有產生新高、複製成功或防線上移，AI 應降低信心，說明是否已轉為時間失效、Q3 或複製轉修正。

## 12. AI 每日輸出要求

輸出必須符合 `config/enlightenment_ai_judgement_v1.schema.json`，並至少回答：

1. 主要與替代定錨為何？
2. 大、小級各自方向、象限與道氏防線為何？
3. 現在是複製、修正、重置或級數升級？第幾代？
4. 左右階段是否適用？
5. 目前屬於哪個主要情境路由？為何？
6. 位階是否仍有合理空間？
7. 當天狀態是等待、建立計畫、觸發或排除？
8. 什麼事件會推翻本次判讀？

若主要與替代情境衝突到足以改變交易方向或失效點，不能輸出 `TRIGGERED（已觸發進場）`。

## 13. 校準與回測順序

1. 先以 `config/enlightenment_ai_calibration_cases_v1.json` 的正反例檢查 AI 是否理解課程。
2. 每個案例只提供 `ai_visible`，不得提供 `evaluator_only`。
3. 凍結本規格與 AI 提示後，再回放 2026-05-01 起的每日選股名單。
4. 第一輪固定每筆一萬元、不加碼、同一基準出場，只比較進場品質。
5. 凍結進場點後，再比較母單、加兩次、加三次。
6. 最後才比較固定防線、分層結構防線與末代分段退出。

台半、百容、康舒及過去已討論的輸贏案例都已參與規格形成，只能算 `RESEARCH_CALIBRATION（研究校準）`，不得宣稱為樣本外證據。規格凍結後的未來新名單才是 `FORWARD_VALIDATION（前向驗證）`。
