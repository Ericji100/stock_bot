# 啟蒙層 AI 綜合判讀規格 v2

版本：`enlightenment-ai-judgement-v2`
建立日期：2026-09-06
用途：日 K 選股名單的結構判讀、進場觸發與因果回測規格
狀態：`FROZEN_FOR_RESEARCH（研究規則已凍結）`

## 1. 版本定位

V2 的直接基礎是 [`啟蒙層 AI 綜合判讀規格 v1`](enlightenment-ai-judgement-v1.md)，不是名稱中帶有 v2 的回測程式或報表。

```text
V2
= V1 的定位、資料、因果、結構、狀態、部位與回測流程
+ 四個主要情境的完整成立、觸發、排除、失效與轉換規範
+ 每日判讀的逐項 PASS／FAIL／UNKNOWN 稽核
```

V1 保持唯讀。V2 不引入批次回測 V2 的五分門檻、0.5ATR 追價線或特定出場公式；那些是回測參數，不是判讀規格 V1 的內容。

## 2. 分工與來源標記

本規格位於上游選股之後，不是新的選股器，也不把課程簡化成單一公式。

- 程式負責行情、除權息、指標、可見日期切斷、狀態保存、成交模擬及績效。
- AI 負責定錨、級數、太極、道氏、四象限、左右、位階、情境與觸發。
- 每個結論都要附日期、價格、主要與替代解讀及失效，不接受只有結論沒有證據。

來源標記沿用 V1：

- `COURSE_SOURCE（課程明確內容）`
- `RESEARCH_EXTENSION（本研究延伸）`
- `BACKTEST_PARAMETER（回測參數）`
- `USER_CALIBRATION（使用者校準）`：補充台半、百容、康舒的判讀案例；只作校準，不是績效證據。

主要課程來源：

- `course_knowledge_base/啟蒙交易班/整理成果/啟蒙交易班_課程整理.md`
- `course_knowledge_base/啟蒙交易班/整理成果/四象限戰法強化_完整課程整理.md`

## 3. 十條不可違反的因果規則

本節逐條沿用 V1：

1. 判讀日只能使用該日收盤以前已知資料。
2. 日 K 收盤成立的 `TRIGGERED（已觸發進場）`，下一交易日開盤才模擬成交；不再增加第二次確認。
3. 當日高低點與樞紐只有在當時可確認時才能使用，不能用後續 K 棒事後把最低點當成當日買點。
4. 同股、同日、同方向的多個訊號若描述同一段行情，只建立一個部位；其餘保存為證據。
5. 第一個實際成交永遠是 `MOTHER（母單）`；錯過先前理論點後的首次成交仍是母單。
6. 虧損中的持倉禁止加碼。
7. 每筆計畫必須指出結構失效；無法指出時不得觸發。
8. 訊號使用公司行動還原後技術價格；損益使用實際成交價格，另計股利、權值與成本。
9. 小級／部位停損只結束該 episode；大級仍有效時可等待新小結構再次進場。
10. 再次進場不得沿用已失效的舊觸發或防線，必須建立新母單、失效點與 episode 編號。

額外的稽核要求不是新交易規則：作用中未完成段的終點必須為空或 `FORMING（形成中）`；不得用回測結果修改定錨、級數、世代或觸發日。

## 4. 資料充分性與 MACD

`BACKTEST_PARAMETER（回測參數）`：監控日前目標至少 750 個有效交易日，前 200 根暖機，其後至少 500 根供結構與世代判讀。

最低希望看到：

```text
負向區有效低點 L0
→ 正向區有效高點 H1
→ 下一負向區有效低點 L1
→ 當前發展段
```

MACD 21/55/55 只協助切分候選波段及判斷動能：

- 黃金交叉前有效低點可作向上定錨起點候選，交叉日不是自動起點。
- 正向區有效高點可作終點候選，翻黑日不是自動終點。
- 還要檢查乾淨度、幅度、斜率、破壞性、道氏防線與長均線。
- 持續翻紅可支持作用中新錨，不能證明新錨已完成。
- 背離只能作風險證據，不直接反轉方向。

資料不足標 `DATA_INSUFFICIENT（資料不足）`。不能高信心判大定錨複製；新上市股可獨立檢查新生定錨，但須與完整歷史樣本分開統計。

## 5. 定錨程序

AI 至少提交一個主要定錨與零至兩個替代定錨。每個定錨必填：

- 大／小級、方向、起訖日期與價格；未完成終點不得回填。
- 幅度、歷時、相對 ATR、斜率、反向 K、影線及內部樞紐。
- 破壞的重要區間、箱型或同級道氏防線。
- `FORMING／CONFIRMED／CORRECTING／INVALIDATED／SUPERSEDED`。
- 失效價、來源日期與級數。
- `CLEAN（乾淨）／MEATY（有肉）／DESTRUCTIVE（具破壞性）／TRACEABLE（可追溯）` 各自的 `PASS／FAIL／UNKNOWN` 與證據。

有效定錨至少回答：「從哪裡開始、往哪裡、破壞了什麼、哪裡失效。」只看到上漲、均線交叉或 MACD 翻紅而回答不出這四點，不算定錨。

股票日 K 的 105MA、144MA、慣用均線及 Elson 的長期向上價格面，只作線與面的證據；不能單獨建立觸發。

## 6. 太極、世代、象限與大小級

### 6.1 太極與世代

```text
1：ANCHOR_LEG_1（定錨）
2：CORRECTION（修正）
3：COPY_LEG_3（第一代複製）
4：CORRECTION（修正）
5：COPY_LEG_5（第二代複製）
5以後：LATER_GENERATION（更後代）
```

後代需比較幅度、修正比例、時間、斜率、乾淨度、內部轉折、是否創高及象限變化。第五段、第三次攻擊或更後代不自動禁止，但必須降級並揭露剩餘空間、追價與複製失敗風險。

- 複製弱化：停止追價並降級，不自動反手。
- 複製失敗：檢查 `COPY_TO_CORRECTION（複製轉修正）`。
- 修正破壞父代起點或大級防線：原朝代失效，等待重置。
- 級數升級必須保存舊版本及升級事件，不能事後抹除。

### 6.2 動態四象限

- Q1：趨勢性與波動率同步增加；順勢攻擊。
- Q2：趨勢性降低而波動率增加；多空換手，必須指出策略方向。
- Q3：趨勢性與波動率都降低；沒有足夠效率與空間，四情境都不觸發。
- Q4：趨勢延續而波動率收縮；順勢等待修正完成與再次發動。

象限要比較至少相鄰兩至三段，不能以站上／跌破單一均線決定。不同象限仍可策略共振，例如大級 Q4 等順勢低接、小級 Q2 等向上逆勢拉回；但必須說明兩者都要求下一個可交易方向向上。

### 6.3 大、小兩個工作級數

- 大級決定方向、空間、朝代及 campaign 是否有效。
- 小級決定當下控制權、觸發、加減碼節奏與 episode 防線。

小級可以暫時取得發球權，但不能自動推翻大級。AI 必須說明誰控制、另一級造成什麼風險，以及哪個事件會改變控制權。

## 7. 道氏、防線與左右戰法

大、小級分別保存 `BULL／BEAR／TRANSITION／UNDEFINED`。每條防線保存級數、方向、價位、來源樞紐、建立日、失效日及版本。

防線只能因果建立：一段攻擊已實際造成同級創高／創低後，才可回指其發動樞紐。小級防線被破不等於大級定錨失效。

- `LL（左左）`：大防線未破的末段猜測。
- `LR（左右）`：大防線未破，小級慣性已翻向。
- `RL（右左）`：大防線突破後第一次有效拉回。
- `RR（右右）`：右側拉回後再次延續突破。
- `DIRECT_TO_RIGHT（直接進入右側）`：快速 V 轉穿越防線，沒有清楚左側。

左右是結構狀態，不表示四個位置全部成交；第一個實際成交仍是母單。

## 8. 情境選擇與互斥

四個情境是可轉換狀態，不是股票永久分類，也不是四個投票器。先辨識控制中的大級背景及太極階段，再選唯一主要情境：

1. 成熟多頭朝代仍控制，當前是朝代內修正與再發動：`MATURE_TREND_PULLBACK`。
2. 有已完成向上父代、明確修正，正啟動下一代複製：`MACRO_COPY_RESONANCE`。
3. 大級空頭朝代尚未完成反轉，正在走 LL／LR／RL／RR：`BEAR_REVERSAL_LEFT_RIGHT`。
4. 沒有成熟多頭或可複製父代，但形成早期破壞性向上新錨：`FRESH_Q1_EXPANSION`。
5. 證據不足或解讀衝突：`UNRESOLVED_NO_TRADE（結構未定義，不交易）`。

主要情境只有一個，可保存最多兩個替代情境。替代解讀若會改變方向、失效點或成交角色，不得 `TRIGGERED`。禁止使用「其他三種都不像，所以就是新生定錨」的 else 分類。

## 9. `MATURE_TREND_PULLBACK（長多慣性拉回再發動）`

### 9.1 定義與情境邊界

大級多頭朝代及長期價格慣性已被市場反覆確認；目前是原朝代內的良性修正，小級重新取得向上控制權。它不是剛產生第一個向上新錨，也不是父代大定錨後正在做第一次明確複製。

### 9.2 八項必要條件

1. 有效且仍控制的大級向上定錨／多頭朝代，能指出起點、主要推進、多頭防線與失效。
2. 長多慣性已有歷史證明：至少一個成功推進加修正／複製，或同級高低點持續墊高並跨越足夠時間；不能只因今日站上長均線。
3. 105MA、144MA或該股慣用均線的方向及歷次支撐行為支持長多；均線只作線層證據。
4. 當前下降段是原朝代內修正，沒有確認跌破大級多頭防線或父代失效點。
5. 太極父代、目前修正及世代已標記；第五段或更後代必須降級。
6. 大、小級象限已動態判讀：優先大級 Q4 等小級重啟，或大級 Q1 的第一次淺修正；大級 Q2 只有在防線有效且向上策略清楚時作低信心候選；Q3 不做。
7. 小級出現因果可確認的向上控制權轉換，不以碰均線、單根紅 K 或 MACD 翻紅單獨觸發。
8. 有本次部位／小級失效點，不能故意放寬到遠端大級低點。

### 9.3 觸發路徑

- `Q4_TO_Q1_RELAUNCH`：長多不壞，修正波動收縮；小級突破修正段空頭防線並由 Q4 轉 Q1，收盤觸發。
- `SMALL_DOW_REVERSAL`：小級低不破低、再高過高，或向上反向定錨突破修正段道氏防線，收盤觸發。
- `MA_HABIT_RECLAIM_WITH_STRUCTURE`：拉回慣用均線、105MA／144MA後先止跌；收復中短均線時同步突破因果小樞紐或形成再發動，收盤觸發。
- `FIRST_SHALLOW_PULLBACK`：成熟多頭 Q1 延伸中的第一次淺修正守住新防線，再突破拉回小樞紐，收盤觸發。

已知道等待事件與失效，但事件尚未收盤完成時，只能 `ARMED（已建立進場計畫）`。

### 9.4 禁止誤判

- 只有站上 105MA／144MA、長均線斜率向上、碰到或收復某均線。
- 只有 MACD 翻紅、成交量放大、20日新高或單根紅 K。
- 大級多頭防線或父代起點已失效。
- 實際是父代後第一次大級複製、空頭末段反轉或第一個新生定錨。
- Q3、Q2方向未明或大小級控制權衝突。
- 第五段／第三次攻擊後明顯弱化、未創高、內部轉折增加或末段爆量。
- 找不到鄰近的因果部位失效點。

### 9.5 失效、再進與轉換

- 小級／部位停損：結束 episode；大級朝代仍有效則轉 `REENTRY_WATCHING`，等待新修正及新觸發。
- 大級多頭防線或父代失效：`CAMPAIGN_INVALIDATED`，移出監控直到上游重新選入。
- 複製轉修正或長多效率消失：轉 `COPY_TO_CORRECTION／UNRESOLVED`，不為持倉更換週期。

## 10. `MACRO_COPY_RESONANCE（大定錨複製共振）`

### 10.1 定義與情境邊界

一段有效大級向上父代已完成，之後有清楚的大級修正；修正末端的小級向上反向定錨突破修正段空頭防線，下一個向上複製回合開始。它不是任何普通均線拉回。

### 10.2 八項必要條件

1. 已完成、有效的大級向上父代，具有起訖、方向、級數、破壞證據與失效。
2. 父代後有大級修正，修正未確認破壞父代起點或大級多頭防線。
3. 父代、修正與目前世代已標記；優先 `COPY_LEG_3`，第五段或更後代降級。
4. 修正段的小級空頭道氏防線已因果建立。
5. 小級向上反向定錨形成，並突破修正段防線，或完成等價的低不破低、高過高。
6. 大、小級對下一段都要求向上，至少形成策略共振。
7. 不是 Q3、複製失敗、複製轉修正或末代耗竭。
8. 有本 episode 的小級失效點，不只使用遠端父代低點。

### 10.3 觸發路徑

- `BREAK_THEN_RETEST`：突破修正段防線先 ARMED；第一次拉回守住右側低點／新錨起點，再突破小樞紐時觸發。
- `SMALL_REANCHOR_RELAUNCH`：修正末端完成小級向上定錨，收盤突破小級空頭防線並再發動。
- `DIRECT_TO_RIGHT`：同一乾淨破壞段穿越大小級防線，仍在初期且失效鄰近時可觸發；必須揭露假突破與追價風險。

### 10.4 禁止誤判與失效

沒有完成父代、只有均線／20日高／小樞紐、修正仍向下、父代已壞、大小級無共同向上策略、後代弱化、Q3或無部位失效點，皆不得觸發。

小級假突破只結束 episode；父代有效可再監控。父代起點或大級防線失效則結束 campaign。第一代複製持續成功並形成穩定長多慣性後，才轉長多拉回。

台半、百容為 `RESEARCH_CALIBRATION`，不得作樣本外證據。

## 11. `BEAR_REVERSAL_LEFT_RIGHT（空頭末段左右反轉）`

### 11.1 定義與六項必要條件

大級仍是下降定錨或空頭朝代，但可能已到末段；小級由空轉多，以 LL／LR／RL／RR 描述反轉確認。必須同時具備：

1. 有效大級下降定錨，或同級低破低且高不過高的空頭朝代。
2. 大級空頭防線、來源樞紐、建立日及失效規則。
3. 至少一項末段證據：第三次攻擊／第五段、後代弱化、時間或空間耗竭、末跌加速後動能衰退。
4. 已標記 LL、LR、RL、RR 或 `DIRECT_TO_RIGHT`。
5. 大、小級分開；小級翻多不能直接宣稱大級多頭。
6. 有該階段自己的因果失效點。

### 11.2 階段權限

| 階段 | 結構與V2權限 |
|---|---|
| LL | 大防線未破；標準只 WATCHING，不以背離或次低未破單獨建立一般母單 |
| LR | 大防線未破，小級低不破低且高過高；可 ARMED，只有末段證據完整且失效鄰近才可試錯母單 |
| RL | 大防線已破，第一次有效拉回守住右側低點；標準母單首選 |
| RR | RL 後再突破樞紐高；可作首次母單，或持倉獲利時作獨立加碼 |
| DIRECT_TO_RIGHT | 乾淨推進一次穿越大小級防線；首次成交仍是母單，不補買左側部位 |

### 11.3 禁止誤判、失效與轉換

只有 MACD、均線、紅 K 或20日高；空頭仍在初期且向下複製成功；找不到大防線；沒有左右結構；只是普通急彈；Q3或失效過遠，皆不得觸發。

跌破各階段綁定低點即結束 episode。反轉失敗再創同級空頭新低，回到空頭延續。大級空頭防線遭乾淨、有肉、具破壞性的向上定錨確認突破後，轉新生定錨；不能永久停留在空頭反轉標籤。

## 12. `FRESH_Q1_EXPANSION（新生定錨直接擴張）`

### 12.1 定義與七項必要條件

空頭末端、盤整或未定義背景中，形成第一段或第一次修正後早期的向上新錨；尚未有成熟長多朝代或可辨識父代複製。必須同時具備：

1. 作用中或剛確認的新生向上定錨，含起點、當前端點、方向、級數、狀態與失效。
2. 新錨乾淨、有肉、具破壞性、可追溯，至少破壞重要區間或同級道氏防線。
3. 動態 Q1 候選或已確認：持續創高，趨勢性與波動率同步擴張。
4. 太極位於 `ANCHOR_LEG_1` 或第一次修正後 `COPY_LEG_3` 早期；不得作殘餘分類。
5. MACD只支持由負收斂轉正與擴張，不單獨成立。
6. 能說明距起點、相對ATR、同向攻擊序號及為何仍是初期。
7. 有新錨起點或第一次有效修正低點作因果失效。

### 12.2 觸發路徑

- `INITIAL_DESTRUCTIVE_EXPANSION`：新錨收盤破壞重要區間／防線，仍在最初破壞段且失效鄰近；否則 `NO_CHASE`。
- `FIRST_SHALLOW_CORRECTION_RELAUNCH`：第一段後首次良性修正守住新錨起點／防線，再突破小級空頭防線或小樞紐；優先母單。
- `CONTINUATION_ADD`：母單已有收盤獲利，且不同日期有獨立修正及再突破，才取得加碼資格。

### 12.3 禁止誤判、時間失效與轉換

只有單根長紅、MACD、均線交叉、20日高；沒有破壞性；已多代複製；Q2穿頭破底或Q3；內部太亂；已有完成父代加修正；已有成熟長多朝代，皆不得判本情境。

新生 Q1 應快速證明方向。合理時間內不續創高、同級樞紐增加或斜率消失，取消當次計畫並重估；不能因後來上漲延後失效。第一段完成並修正、下一向上回合開始複製時轉大定錨共振；反覆成功形成長多慣性後才轉長多拉回。

康舒的校準狀態順序為：

```text
空頭末段左右反轉
→ 新生定錨直接擴張
→ 第一段完成／修正
→ 下一段複製
→ 大定錨複製共振
```

## 13. 共通排除與觸發語意

以下只能 `REJECTED（不合格）`、`WATCHING（監控中）`、`STRUCTURE_MAPPED（結構已辨識）` 或 `DATA_INSUFFICIENT（資料不足）`：

- 任何必要條件為 `FAIL／UNKNOWN`。
- Q3、定錨不清、大小級衝突且控制權不明。
- 沒有部位失效點，或防線遠到風險報酬明顯惡化。
- 後代變短、變慢、變亂，複製失敗仍追價。
- 單一均線、MACD、量能、紅 K 或突破，沒有面與結構支持。

`ARMED（已建立進場計畫）` 表示等待事件、觸發與失效都已寫清楚，但事件尚未於收盤完成。`TRIGGERED（已觸發進場）` 表示當日收盤已完成，不需再等下一根收盤；下一交易日開盤執行。

只有主要情境必要條件全 PASS、沒有 blocking 排除、主要與替代結構不衝突、監控有效、觸發已完成、失效可因果確認且同日訊號已去重，才能 TRIGGERED。加碼還要額外通過原持倉收盤已有獲利及不同日期獨立結構。

## 14. 狀態、母單、加碼與再進場

V1 的狀態完整保留：

| 狀態 | 定義 |
|---|---|
| `WATCHING（監控中）` | 尚未建立足夠清楚的結構 |
| `STRUCTURE_MAPPED（結構已辨識）` | 已能說明主要與替代結構，但沒有可執行計畫 |
| `ARMED（已建立進場計畫）` | 等待事件、觸發及失效已知，事件尚未成立 |
| `TRIGGERED（已觸發進場）` | 當日收盤已完成條件；下一交易日開盤執行，不再多等一次收盤 |
| `REJECTED（不合格）` | 當前機會不符合結構、位階或可執行風險 |
| `INVALIDATED（結構失效）` | 原計畫或原錨遭破壞，必須重置 |
| `DATA_INSUFFICIENT（資料不足）` | 資料無法支撐所需級數判讀 |
| `OPEN（持有中）` | 已成交且尚未完全出場 |
| `ADD_ARMED（已建立加碼計畫）` | 持倉已有市場證明，等待下一個獨立加碼事件 |
| `EXIT_WARNING（出場警戒）` | 有衰退或末代警告，但尚未完成強制出場條件 |
| `STOPPED（停損出場）` | 本 episode 因小級或部位防線失效結束；不等於大級必然失效 |
| `REENTRY_WATCHING（再進場監控中）` | 已停損但大級仍有效，等待新的獨立小結構 |
| `CAMPAIGN_INVALIDATED（大結構交易週期失效）` | 大級定錨或防線遭破壞，停止沿用本 campaign |
| `REMOVED_FROM_WATCHLIST（已移出監控）` | 大級失效後移出，必須等上游重新選入 |
| `CLOSED（交易已結束）` | 已完全出場 |

後續部位比較仍為：

1. `MOTHER_ONLY_10K（母單一筆一萬元）`
2. `MOTHER_PLUS_2（母單加兩次）`
3. `MOTHER_PLUS_3（母單加三次）`

加碼必須同時符合：持倉收盤獲利、不同日期獨立結構、防線上移或加碼有獨立失效、同日證據去重、非 Q3／末代衰退／大小級嚴重打架。

小級停損後，episode 獨立結算；大級有效則轉 `REENTRY_WATCHING`。重新進場必須新修正、新觸發、新母單、新 episode 及新防線。大級失效則 `CAMPAIGN_INVALIDATED` 並移出，直到上游重新選入。

## 15. 每日 AI 輸出

輸出必須符合 [`config/enlightenment_ai_judgement_v2.schema.json`](../config/enlightenment_ai_judgement_v2.schema.json)，至少包含：

1. 上游入選、監控與 campaign。
2. 資料充分性、公司行動與股利口徑。
3. 主要及替代定錨。
4. MACD 完整週期骨架及輔助角色。
5. 大、小級方向、象限、道氏、防線來源與版本。
6. 太極父代、目前段、世代、複製與修正品質。
7. 左右階段、位階、控制權與剩餘空間。
8. 四個情境每項條件的 `PASS／FAIL／UNKNOWN` 與證據。
9. 所有 blocking 排除。
10. 主要／替代情境、狀態、等待事件、觸發、部位失效與大級失效。
11. 母單／加碼／再進角色與同日去重。
12. 最新可見日、未用未來資料、結果未提供 AI、未回填未完成段終點。

## 16. 校準、回測順序與限制

1. 先用校準案例檢查 AI 是否理解，不把 `evaluator_only` 給 AI。
2. 凍結 V2 與提示後，再回放每日選股名單。
3. 第一輪固定每筆一萬元、不加碼、同一基準出場，只比較進場品質。
4. 凍結進場後再比較母單、加兩次、加三次。
5. 最後才比較出場；不在建立 V2 情境時同時最佳化部位與停利。

台半、百容、康舒及過去討論案例都參與規格形成，只能算 `RESEARCH_CALIBRATION（研究校準）`。V2 規則完整性通過不代表回測獲利或樣本外有效；凍結後的新名單才可作 `FORWARD_VALIDATION（前向驗證）`。
