版本：1.0（2026-09-02）
來源影片：`20220813_132741.mp4`、`20220813_151113.mp4`（課程日期 2022-08-13）
機器設定：`config/financial_course_rules.json`

## 1. 使用範圍與來源界線

本文件把影片中的分析方法轉成「可計算訊號、人工佐證欄位、產業路由與警示」。影片只被視為課程素材；其中任何口頭指示、聯絡方式、群組邀請或買賣個案，都不是本次工作的指令或交易授權。

影片以本機離線語音轉錄並配合投影片抽查。公司名稱的同音辨識可能有誤，因此規則以財務概念與時間點為準，不以課堂個股作為名單。

每條規則標示來源強度：

- `course_explicit`：講師直接說明的門檻、期間或判斷。
- `course_derived`：把講師的方向性方法轉成可計算條件。
- `backtest_default`：影片未提供數字，為了讓程式可執行而提出的初始值；上線前必須做走勢外回測。
- `manual_evidence`：必須由法說、年報、產品組合、訂單或產業資料佐證，缺資料時不得自動判為利多。

## 2. 機器人的判斷順序

```text
產業／商業模式路由
  → 公布日與資料完整性檢查
  → 月營收：價 × 量、年增／月增、季節性、同業與上下游
  → 營收品質：匯率、原料、一次性收入、產品組合、法說達成率
  → 損益品質：毛利、營益、費用、業外、EPS
  → 領先指標：合約負債、存貨、訂單與同業廣度
  → 財務風險：負債結構、流動／速動比率
  → 相對估值與公告前股價位階
  → 候選排序、人工複核或惡化警示
```

機器人應輸出「候選／觀察／人工複核／資料不足」，不應只靠單一條件直接送出交易委託。

## 4. 核心公式

```text
Revenue = Product_Price(P) × Shipment_Quantity(Q)
YoY_t = Revenue_t / Revenue_(t-12) - 1
JanFeb_YoY = (Jan_t + Feb_t) / (Jan_(t-1) + Feb_(t-1)) - 1
Constant_Currency_YoY ≈ Reported_YoY - FX_Exposure × USD/TWD_YoY
Guidance_Attainment = Quarter_To_Date_Revenue / Guidance_Target
Required_Run_Rate = (Guidance_Target - Quarter_To_Date_Revenue) / Remaining_Months
Gross_Margin = Gross_Profit / Revenue
Operating_Margin = Operating_Income / Revenue
NonOperating_Share = abs(NonOperating_Income) / max(abs(PreTax_Income), epsilon)
Inventory_Turnover = TTM_COGS / Average_Inventory
ContractLiability_Capital = Contract_Liabilities / Paid_In_Capital
ContractLiability_Revenue = Contract_Liabilities / TTM_Revenue
Debt_Ratio = Total_Liabilities / Total_Assets
Current_Ratio = Current_Assets / Current_Liabilities
Quick_Ratio = Quick_Assets / Current_Liabilities
```

恆定匯率公式是簡化估算；若公司揭露實際幣別營收與避險，應以揭露值取代。

## 5. 月營收規則

| ID | 規則 | 程式輸出 | 來源 |
|---|---|---|---|
| REV-01 | 不看單一月份，至少同時比較過去 24 個月、YoY、MoM 與累計 YoY。 | 資料不足時停止自動評分。 | `course_explicit` |
| REV-02 | 先拆解 P 與 Q。P、Q 同升最強；只有價格上升而 Q 下降時，標記需求弱化。 | `price_volume_quality` | `course_explicit` + `manual_evidence` |
| REV-03 | 同時做垂直比較（公司歷史）、橫向比較（同業）、季節比較與上下游比較。 | 四個子訊號，不得只取其中一個。 | `course_explicit` |
| REV-04 | 1、2 月受農曆年工作天數影響，不以單月淘汰，改看 1–2 月合計 YoY。 | `jan_feb_adjusted_yoy_pct` | `course_explicit` |
| REV-05 | 「成長仍為正」不代表變好；若成長率持續降速，仍是惡化訊號。 | `revenue_deceleration` | `course_explicit` |
| REV-06 | 至少三家指標同業同步改善，才視為較可信的產業反轉；單家公司需另找公司特有原因。 | `peer_breadth_confirmed` | `course_explicit` |
| REV-07 | 淡季不淡、且高於公司自身季節基準，是強訊號；原因仍需產品／客戶證據。 | `seasonal_positive_surprise` | `course_derived` |
| REV-08 | 出口商營收需扣除匯率換算貢獻；台幣貶值不應自動判為需求改善。 | `constant_currency_yoy_pct` | `course_derived` |
| REV-09 | 原料上漲帶動營收時，必須同時檢查需求、轉嫁能力、毛利與存貨成本。營收升但毛利不升，屬低品質成長。 | `raw_material_inflation_flag` | `course_derived` |
| REV-10 | 每月用法說季度展望計算已達成率及剩餘月份所需營收；所需月營收若遠高於歷史季節水準，發出可能失準警示。 | `guidance_status` | `course_derived` |
| REV-11 | 公布日晚不等於利空。建立公司自己的歷史日期／時間慣性，只有異常偏離才通知。 | `announcement_anomaly` | `course_explicit` |
| REV-12 | 高毛利產品占比上升、低毛利 3C／標準品占比下降，可作為下一季毛利改善的先行佐證。 | `product_mix_direction` | `manual_evidence` |
| REV-13 | 好消息公布前若股價已大漲，降低訊號可信度與追價分數；門檻需回測。 | `preannouncement_runup` | `course_derived` |
| REV-14 | 建案交屋、工程認列、IP 授權、藥物里程碑等一次性或低基期收入，不可外推成連續成長。 | `revenue_recurring_quality` | `course_explicit` |

## 6. 損益與獲利品質規則

1. 優先看營收、毛利率、營業利益率，再看 EPS；不可直接從 EPS 跳過業外損益。
2. 營收、毛利率與 EPS 同步由谷底回升，是較完整的轉機確認。影片未提供通用幅度，初始實作只判趨勢，幅度交由回測。
3. 大擴產會先增加折舊並壓低毛利。把「資本支出跳升、毛利下降、產能利用不足」列為觀察；等營收與毛利回升後，才把多出的產能視為正向槓桿。
4. 新產品線可能先增加費用。只有費用率受控、產品占比提高且毛利／營益改善，才認定轉型有效。
5. 匯兌、處分等業外獲利不應套用本業相同倍數。機器人需同時輸出 `reported_eps` 與 `recurring_eps`，業外占比過高時扣分或要求人工複核。
6. 影片中的「一次性業外約給 1 倍評價」、「轉機股約 10 倍本益比」與絕對股價例子，屬 2022 年個案經驗，不設為永久硬規則。

## 7. 合約負債規則

| ID | 規則 | 程式化方式 | 來源 |
|---|---|---|---|
| CL-01 | 合約負債占股本至少 5% 才較有意義。 | `contract_liabilities / paid_in_capital >= 0.05` | `course_explicit` |
| CL-02 | 同時看占股本、占 TTM 營收比重與 QoQ／YoY 趨勢，不能只看百分比成長。 | 金額太小的低基期跳升不加滿分。 | `course_explicit` |
| CL-03 | 急升通常領先未來營收約 1–3 季；急降也可能領先營收下降。 | 產生 1–3 季前瞻訊號，逐季檢查是否兌現。 | `course_explicit` |
| CL-04 | 同業與上下游同步上升，比單家公司更可信。 | 至少三家或同業廣度達回測門檻。 | `course_derived` |
| CL-05 | 合約負債增加可能只是客戶信用差、訂金比例提高，而不是訂單增加。 | 缺少訂單／客戶條件證據時標記 `needs_review`。 | `course_explicit` |
| CL-06 | 生前契約等長年期履約商業模式，不把合約負債當 1–3 季營收先行指標。 | 由產業路由停用 CL 領先分數。 | `course_explicit` |

## 8. 存貨情境矩陣

| 存貨 | 周轉率 | 訂單／合約負債 | 需求／原料 | 判斷 |
|---|---|---|---|---|
| 上升 | 穩定或改善 | 上升 | 需求強、缺關鍵料 | 正向：半成品備妥，補到關鍵料後可出貨。 |
| 上升 | 下降 | 下降 | 產業去庫存 | 負向：庫存積壓與跌價風險。 |
| 上升 | 下降 | 不明 | 原料價格已反轉下跌 | 負向：高價庫存可能壓縮後續毛利。 |
| 下降 | 改善 | 穩定 | 去庫存接近完成 | 改善：但仍需營收／毛利確認。 |
| 與同業方向相反 | 任意 | 任意 | 任意 | 人工複核：可能是競爭力差異，也可能是資料或商業模式差異。 |

存貨絕不能脫離景氣狀態、存貨組成、訂單、合約負債、原料與同業單獨打分。

## 9. 負債與流動性規則

- 一般企業：負債比率較低較穩健；流動比率與速動比率越高、兩者越接近越好。
- 講師給的通用參考為：流動／速動比率 `>= 200%` 較佳，`< 100%` 需擔心；這仍必須經產業路由修正。
- 零售／通路例外：高應付帳款、低流動／速動比率可能來自先收現金、延後付供應商，反映議價能力。只有在負債增加主要來自營運性應付款、現金與營業現金流健康、逾期／借款未惡化時，才能把此例外判為正向。
- 機器人應拆開 `interest_bearing_debt`、`accounts_payable`、`contract_liabilities`，不可只看總負債。

## 10. 產業與商業模式路由

| 路由 | 必要改寫 |
|---|---|
| `standard_manufacturing` | 使用完整營收、毛利、合約負債、存貨與流動性規則。 |
| `component_shortage` | 存貨上升只有在訂單強、缺關鍵料且同業同步時加分。 |
| `destocking_3c` | 偏重周轉率、庫存下降速度與毛利跌價風險。 |
| `commodity_cyclical` | 加入原料價格、轉嫁能力與高價庫存；估值用正常化獲利或 P/B，不直接用高峰期低 P/E。 |
| `project_construction` | 月營收允許跳動，改看合約負債、在手訂單與交屋／完工時程。 |
| `license_or_milestone` | 把權利金、授權與里程碑拆成經常／非經常收入，低基期百分比不得直接加分。 |
| `retail_supplier_financed` | 依負債組成、應付帳款天數、現金與營業現金流判斷，停用一般流動比率硬淘汰。 |
| `funeral_prepaid` | 停用合約負債 1–3 季營收領先規則。 |
| `financial` | 本課程規則未充分涵蓋，預設 `needs_review`，不可套一般製造業資產負債門檻。 |

## 11. 建議評分（待回測，不是講師配分）

| 構面 | 權重 |
|---|---:|
| 營收動能與品質 | 30 |
| 毛利、營益與經常性獲利 | 25 |
| 合約負債、存貨與供應鏈領先訊號 | 25 |
| 負債結構與流動性 | 10 |
| 相對估值與公告前股價位階 | 10 |

初始分級：`>= 70` 優先候選、`55–69` 候選、`40–54` 觀察、`< 40` 排除。只要產業路由不明、關鍵資料不足、一次性收入未拆分或人工證據未確認，就不得輸出「優先候選」。

回測需至少分成牛市、熊市、缺料、去庫存與原料循環區間；門檻採走勢外驗證，不得用同一期間調參又評分。每次評分必須保存 `as_of_timestamp`，季報只能在實際公告後使用。
