# 0050 高低市場狀態差別投入 × 核心持有 v1

本研究是候選分析，不是正式策略改版。訊號、出場、公司行動與交易成本沿用封存 v1.7；唯一策略變數是進場訊號日的市場狀態投入比例，以及是否保留獨立的 20% 長期核心帳。

## 規則

- 訊號日 `MA21 < MA144`：低檔，投入當下戰術帳 100% 可用現金。
- 訊號日 `MA21 >= MA144`：高檔，投入當下戰術帳 50%、75% 或 100% 可用現金；等號歸高檔。
- 核心權重：0% 或 20%，共六組主組合。
- 20% 核心：共同起始日以 100,000 元在正式開盤買進 0050，股利付款後次一正式交易日再投入；不再平衡。
- 戰術帳與核心帳各自記錄現金、股數、成本、股利與分割，禁止互借或補款。
- 持倉期間市場狀態改變時，不加碼、不減碼、不強制出場；禁止疊加部位。
- 正式成交口徑為次一正式交易日開盤；20 基點為主，40／60 基點為成本壓力。訊號日收盤僅作 20 基點成對敏感度。

## 必過閘門

1. 核心 0%＋高檔 100%＋低檔 100%＋次日開盤 20 基點，必須與封存 v1.7 的摘要、逐日帳、交易流水與逐筆明細完全同值。
2. 每次投入比例的分母必須是進場前戰術帳可用現金；未投入部分留現金。
3. 核心與戰術每日合計必須守恆，兩帳現金不得為負。
4. 股利先在除息日鎖權，付款日才成為現金；分割不得製造損益。
5. 所有正式輸出必須兩次獨立重播雜湊一致，並通過 manifest、readback 與報告連結驗證。

## QA3 呈現契約

修正版必須寫入全新的 `v1-qa3` run／report 目錄，不得覆寫 v1 或 qa2。主報告需有可點的建議閱讀順序，14 個編號章節都必須固定包含「測試目的、測試方法、觀察結果、白話結論、對最終決策的影響」。第 08～11 節應直接列出實際數據，不得只丟 CSV 連結。

報告另須提供繁體中文 `trade-details.md`，列出六組主方案的全部回合，並與主報告雙向連結。六線權益圖採兩列三欄短中文圖例；成本壓力圖採六組、每組三根成本柱的分組圖。三張圖均須以實際瀏覽器渲染，確認文字、圖例與邊界沒有重疊或裁切。

逐筆頁的成交價、初始防守價與出場／估值價保留來源 Decimal 的有效小數，不得格式化為整元；金額欄才可四捨五入到整元。出場原因在正文使用「MACD 翻綠」與「固定初始防守」等繁中短語，程式原碼留在 CSV。主報告第一次出現 CAGR、MDD、Calmar 時，寫成「年化報酬（CAGR）、最大回落（MDD）、年化報酬÷最大回落（Calmar）」，後續表格以中文欄名為主。

20% 核心方案的 2006 年度與固定期間報酬，以第一個交易日收盤後、已扣核心建倉費的帳面資產為期初；這是年度／期間序列的報表口徑，不等同直接用原始 500,000 元作期初的全期報酬。
