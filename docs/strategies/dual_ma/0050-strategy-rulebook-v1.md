# 0050 回測策略規則總表 v1

本文件是 0050 歷史回測的 Git 版規則索引。它統一說明曾正式回測的策略、比較線、成交版本與共同帳務規則；績效數字仍以各版本封存報告為準。本文件不改變任何歷史策略，也不把比較基準誤稱為可交易策略。

## 1. 名詞與分類

- **策略**：會依規則產生買賣訊號的模型。
- **成交版本**：同一組訊號改用不同成交時間執行，不是新的訊號策略。
- **買進持有比較線**：可交易的被動比較方法，但不是擇時策略。
- **市場基準**：臺灣加權股價報酬指數換算值，只供比較，不可直接交易。
- **技術分析用價格**：分割時會等比例重訂，只用於均線、MACD、進出場訊號與防守價判定。
- **未還原價格**：市場實際開高低收，只用於成交、費稅、股息再投入與期末清算。

## 2. 全策略共同規則

### 2.1 資料與期間

- 0050 於每個正式交易日都具備監控資格，不需要另外等待選股名單。
- 2006～2026/09 正式研究使用 2005 年作技術指標暖機；暖機資料不得計入績效或成交。
- 正式期間為 2006-01-02 至 2026-09-30。年度只切割同一條連續資產曲線，不逐年重設本金、持倉或監控狀態。
- 技術訊號與未還原成交價必須逐日對齊。分割、股息及交易日曆均按已封存資料包處理。

### 2.2 帳戶、部位與成本

- 初始本金 500,000 元；不借款、不追加外部本金，只買整股。
- 同一策略同一時間只持有一個 0050 部位；持有中不重複進場，賣出當日不重新買進。
- 截止日仍持有時不強制賣出，以當日未還原收盤價扣估計賣出費稅後列入資產。
- 定版主成本為買進與賣出各 20 基點滑價、手續費率 0.0399%（逐筆四捨五入至整元、無最低手續費假設）及 ETF 賣出稅 0.1%。研究版本另保留其明示的成本壓力情境。

### 2.3 公司行動

- 股息資格在除息日依持股鎖定，付款日入現金；策略帳戶的閒置現金於下一次合規進場才使用。
- 0050 股息再投入比較線採付款日未還原收盤價再投入。這是歷史模擬假設，實務是否能同日動用取決於券商入帳時點。
- 2025-06-18 的 4:1 分割只調整股數、成本與技術座標，不是買賣、暴跌或停損事件。

### 2.4 出場與同日衝突

- 價格防守／停損與 MACD 出場同日成立時，價格防守優先。
- 已賣出部位必須等待下一個新的合法進場事件，不得在同一交易日重進。
- 未明示的未來資訊、事後修訂或績效結果不得回頭改寫訊號。

## 4. MA21／MACD 與固定防守家族

### 4.1 `MA21_MACD_21_55_55`：MA21 突破＋移動道氏防線＋MACD

- 空手時，前一交易日技術分析用收盤價不高於前一日 MA21，且當日技術分析用收盤價高於當日 MA21，形成一次新的 MA21 突破。
- 連續站在 MA21 上方不重複進場。
- 持倉期間維護因果 n=2 道氏防線；防線只上移，不下移。
- 價格收盤跌破有效防線時優先出場；否則在 MACD 柱狀值已啟用後，由非負轉負時出場。
- 本策略不要求 MA21 高於 MA144。

### 4.2 `MA21_FIXED_INITIAL_STOP_MACD_21_55_55`：MA21 突破＋固定初始防守＋MACD

- MA21 突破條件與上一策略相同。
- 初始防守價只在進場時，依該次 MA21 拉回區間的可用最低點決定；必須嚴格低於進場參考價。
- 進場後防守價不上移、不繼承進場前的道氏防線；只有分割等單位變更時等比例換算。
- 收盤跌破固定初始防守時優先出場；否則在 MACD 柱狀值已啟用後，由非負轉負時出場。

## 5. MA21／MA144 分流家族

兩種分流策略使用互斥進場來源，且持倉中每天重新判定市場狀態：

- **高市場狀態**：MA21 大於或等於 MA144，等號歸入高市場狀態。空手時只接受 MA21 新突破。
- **低市場狀態**：MA21 小於 MA144。空手時只接受 MACD 柱狀值前一日小於或等於 0、當日大於 0 的綠翻紅。
- MACD 綠翻紅進場時，MACD 出場條件立即啟用。MA21 突破進場時，若柱狀值已大於或等於 0 便立即啟用；否則等待持有後首次回到大於或等於 0 才啟用。
- 啟用後，只有柱狀值前一日大於或等於 0、當日小於 0 才構成 MACD 出場。

### 5.1 `MA21_MA144_REGIME_MOVING_DOW_MACD_21_55_55`：分流移動版

- 高市場狀態：移動道氏防線優先，否則採已啟用的 MACD 紅翻綠出場。
- 低市場狀態：移動防線只維護、不執行，只允許已啟用的 MACD 出場。
- 持倉由低市場狀態切回高市場狀態後，恢復執行當時有效的移動防線。

### 5.2 `MA21_MA144_REGIME_FIXED_INITIAL_STOP_MACD_21_55_55`：分流固定版

- 固定初始防守價的算法與 4.2 相同，進場後不上移。
- 高市場狀態：收盤嚴格低於固定初始防守價時優先出場，否則採已啟用的 MACD 紅翻綠出場。
- 低市場狀態：固定防守價只維護、不執行，只允許已啟用的 MACD 出場。
- 這是目前最終採用的訊號規則。

## 6. 被動比較線與市場基準

|ID|說明|是否可交易策略|
|---|---|---|
|`BUY_HOLD_CASH`|正式期首日以開盤買入 0050，之後不賣出；收到的股息保留現金。|是，被動比較線|
|`BUY_HOLD_REINVEST`|正式期首日以開盤買入 0050，之後不賣出；股息於付款日收盤依既定成本再投入。|是，被動比較線|
|`TAIEX_TOTAL_RETURN_EQUIVALENT_500K`|把 500,000 元按臺灣加權股價報酬指數換算，不扣策略交易成本。|否，只是市場基準|

## 7. 最終定版的兩種成交版本

最終報告只保留 5 條正式比較線：同一套分流固定版訊號的兩種成交版本、兩種 0050 買進持有及一條市場基準。

### 7.1 `FINAL_SIGNAL_CLOSE_20BPS`

- 進場與出場都以訊號當日未還原收盤價成交。
- 只作理想化研究對照，因完整收盤訊號在收盤後才確定。

### 7.2 `FINAL_NEXT_SESSION_OPEN_20BPS`

- 訊號在當日收盤後凍結；進場與出場都排到下一個官方交易日未還原開盤價成交。
- 這是正式執行與歸因的實務主口徑。

兩者使用完全相同的訊號序列與策略規則，不存在「收盤進場、隔日開盤出場」的混合第三版。

## 8. 七方法研究與最終定版的關係

七方法 v1.6 比較的是：

1. `A_LONG`
2. `MA21_MACD_21_55_55`
3. `MA21_FIXED_INITIAL_STOP_MACD_21_55_55`
4. `BUY_HOLD_CASH`
5. `BUY_HOLD_REINVEST`
6. `MA21_MA144_REGIME_MOVING_DOW_MACD_21_55_55`
7. `MA21_MA144_REGIME_FIXED_INITIAL_STOP_MACD_21_55_55`

最終定版不是第八套訊號策略；它選定第 7 項的規則，再分成訊號日收盤與次一交易日開盤兩種成交版本。

## 9. 研究配置不是新策略

- 20／40／60 基點是成交成本壓力測試，不是三套訊號策略。
- 243 組均線與 MACD 組合是參數穩健性研究；正式參數仍為 MA21／MA144 與 MACD(21,55,55)。
- 核心持有 0／20／40／60% 是資產配置研究，不改變策略訊號本身。
- 滾動 3／5／10 年及不同市場狀態是觀察切片，不是新的交易規則。
