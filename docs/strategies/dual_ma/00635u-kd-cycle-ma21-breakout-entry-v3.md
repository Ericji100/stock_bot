## 2. 指標與交叉定義

### 2.1 新進場 KD

- 進場型態使用 `KD(9,9,55)`：RSV 週期 9、K 平滑 9、D 平滑 55。
- 黃金交叉：前一交易日 `K <= D`，當日 `K > D`。
- 死亡交叉：前一交易日 `K >= D`，當日 `K < D`。
- `K = D` 不屬於 `K<D` 或 `K>D` 區段，只能作交叉邊界，不得同時被兩區段接收。

### 2.2 MA21 向上突破

以收盤後確認：

```text
前一交易日收盤價 <= 前一交易日 MA21
當日收盤價       > 當日 MA21
```

不得用盤中一度突破或未收盤資料。

## 3. KD 循環型態

### 3.1 第一段 K<D

辨識第一個完整 `K<D` 區段，分別記錄：

- `L1`：該區段的最低股價及日期。
- `K1`：該區段所有 K 值的最低值及日期。

`L1` 與 `K1` 不要求發生在同一天。若最低值相同，以最早日期作具名 tie-break。

### 3.2 中間 K>D

第一段 `K<D` 經黃金交叉轉為 `K>D` 後，至下一次死亡交叉前，記錄：

- `H1`：該 `K>D` 區段的最高股價及日期。

`L1 -> H1` 是第一段上漲走勢。本輪不加入最小漲幅門檻；振幅只作報告分析。

### 3.3 第二段 K<D 與 K 值低點墊高

中間 `K>D` 經死亡交叉後進入第二段 `K<D`。從第二段開始日至每一候選訊號日，因果地計算：

```text
K2_so_far = 第二段 K<D 已經發生部分的最低 K 值
```

進場候選必須滿足：

```text
K2_so_far > K1
```

此條件比較兩段 `K<D` 的最低 K 值，不是比較 MA21 突破日的單一 K 值。

### 3.4 訊號窗口與當日 KD 狀態

MA21 突破可以發生在：

1. 第二段 `K<D` 仍在進行的任一日；或
2. 第二段 `K<D` 結束、首次轉為 `K>D` 的黃金交叉當日。

突破當日不要求 `K<D`，也不要求突破當日 `K > K1`。唯一 K 強弱條件是當時已可觀察的 `K2_so_far > K1`。

若突破發生於第二段仍在進行時，只能使用截至突破日已發生的 K 值；進場後未來 K 再創低不得追溯取消交易。若突破當日同時轉為 `K>D`，第二段 K 最低值已完整確定。

若至首次轉回 `K>D` 當日仍未出現合法 MA21 突破，本循環失效。該第二段可向前滾動成下一循環的第一段；不得重複使用已消耗型態或事後挑選區段。

每個完整循環最多產生一次進場訊號。第一次合法訊號成立時，該循環立即且永久消耗；
不論後續結果為成交、已有部位排除、待次開成交或次開價低於／等於防守價而取消，均不得
讓同一循環再次產生訊號。訊號消耗屬型態掃描狀態，不得依賴訂單或部位狀態回復資格。

## 4. 兩個研究策略

### 4.1 策略 C：均線分流版

- 訊號日 `MA21 < MA144`：只使用本契約第 3 節的新 KD 循環型態進場。
- 訊號日 `MA21 > MA144`：完全沿用已驗收原策略的高檔區間進場與策略 B 出場。
- `MA21 = MA144`：不得開新倉。
- 持倉後 MA21／MA144 關係改變，不得因此強制出場或切換既有部位規則。

### 4.2 策略 D：不分均線版

- 所有新進場只使用本契約第 3 節的新 KD 循環型態。
- MA144 僅作診斷，不得影響訂單、事件、部位或帳務。

## 5. 防守、R 與出場

- 新型態的初始防守價為 MA21 突破訊號日最低價。
- 次一交易日開盤版本若實際開盤成交價 `<=` 初始防守價，取消該筆進場並具名記錄，不建立無有效風險距離的部位。
- 固定初始防守永遠優先，且不得向下放寬。
- 沿用既有已驗收的費後 `1R`、`2R` 與永久 armed 契約。
- 出場 KD 維持既有策略 B 的 `KD(9,9,55)`；本版進場與出場的 KD 參數相同，但進場循環與出場交叉仍是互相獨立的因果狀態。
- 2R 前死亡交叉不得出場或追溯使用；2R armed 後第一個新的合法 KD 死亡交叉出場。
- armed 當日若同時形成合法新死亡交叉，依既有已驗收事件順序處理。
- 防守與 KD 出場同日成立時，防守優先。

## 6. 成交時間

兩個策略各自輸出兩個成交版本，且進場與出場必須使用同一版本：

1. `SIGNAL_CLOSE`：訊號日收盤成交，作理想化 parity 對照。
2. `NEXT_SESSION_OPEN`：下一個官方交易日開盤成交，作實務主口徑。

不得使用未來交易日、未收盤資料或事後修正訊號。

## 9. 測試與報告規格

### 9.1 必測邊界

- KD 等號、交叉、區段邊界與不完整首尾資料。
- `L1`／`K1` 不同日、相同最低值 tie-break。
- `K2_so_far = K1` 必須排除，只有嚴格 `>` 才可通過。
- 突破日仍為 K<D、突破日同時轉 K>D 兩種合法案例。
- 第二段結束仍未突破時型態失效與向前滾動。
- 同一循環不得重複進場，已消耗型態不得重用。
- `FILLED`、`POSITION_ALREADY_OPEN` 與 `NEXT_OPEN_CANCEL` 三種結果都必須具名驗證為已消耗。
- 全檔每個 `(line_id, cycle_id)` 的 `signal_generated`、`entry_signal_generated` 與
  `FILLED` 各自不得超過 1；修正版循環進場交易筆數亦不得超過 1。
- 策略 C 的 `<`／`>`／`=` 邊界與持倉跨 regime 不強平。
- 策略 D 改寫全部 MA144 診斷值後，訂單、事件與帳務 exact parity。
- 次開成交價低於或等於防守價時取消進場。
- 固定防守、2R、armed、KD 出場、費稅及每日現金／股數／equity 守恆。
