# 00635U 雙均線策略 A／B 規則書 v1

本規則書凍結 00635U 正式研究前的策略與帳務契約。它不包含正式績效。

## 1. 共用帳戶與成本

- 連續新臺幣 500,000 元帳戶；不借款、不追加本金、不逐年重設。
- 同時只持有一個 00635U 部位，只買整股；賣出日不重新買進。
- 每次進場以當下可用現金為上限，並沿用 0050 的 `size_entry`：估計初始風險不得超過該次可用資金 20%。所以每次投入金額不是固定 50 萬，而是「可用現金、整股與 20% 初始風險上限」共同決定。
- 手續費率 0.0399%，逐筆四捨五入至整元且基準不設最低手續費；ETF 賣出稅 0.1%。主情境買賣各 20bps 滑價，壓力情境 40／60bps。
- 截止仍持有時，以當日未還原收盤價扣估計賣出費稅後計入資產，不強制成交。
- 每日必須滿足 `equity = cash + after-cost liquidation value` 且現金不可為負。

## 2. 共用進場分流

- 高 regime：`MA21 >= MA144`，等號歸高 regime。只有前日技術收盤不高於前日 MA21、當日技術收盤高於當日 MA21的新突破可進場。
- 低 regime：`MA21 < MA144`。只有 MACD(21,55,55) 柱狀值前日 `<= 0`、當日 `> 0` 的綠翻紅可進場。
- 固定初始防守取本次 MA21 拉回階段低點、前一交易日低點與訊號日低點的最小值；必須嚴格低於技術進場價。
- 持有中不重複進場。所有判斷只使用當日及更早資料。

## 3. 策略 A：0050 最終採用版

ID：`A_FIXED_STOP_MACD_21_55_55`

- 高 regime 日：固定初始防守優先；否則使用已啟用的 MACD 紅翻綠出場。
- 低 regime 日：固定防守只維護、不執行；只允許已啟用的 MACD 紅翻綠出場。
- MACD 綠翻紅進場立即 armed；MA21 突破進場若柱狀值已非負則立即 armed，否則等待持有後首次非負。
- armed 永不取消；只有柱狀值前日 `>= 0`、當日 `< 0` 是新紅翻綠。
- 防守與 MACD 同日成立時，固定防守優先。

## 4. 策略 B：只改高 regime 進場部位

ID：`B_FIXED_STOP_2R_KD_9_9_55`

高 regime 的 MA21 突破部位：

1. 固定初始防守從進場起到離場始終有效，即使之後日 regime 轉低也不暫停。
2. 尚未達成淨成本 2R 前，忽略 KD 與 MACD 的獲利出場；固定防守仍優先。
3. 以實際股數及完整一趟買賣滑價、手續費與 ETF 稅計算：

   `initial_R = buy_total - stop_sale_net`

   `mark_net_pnl = marked_sale_net - buy_total`

   當 `mark_net_pnl >= 2 * initial_R` 首次成立，KD 出場永久 armed。達到 2R 本身不賣出。
4. armed 後只在 KD(9,9,55) 出現「前日 K>=D，當日 K<D」的新死叉出場。
5. 若 armed 當時早已 `K<D` 且當日沒有新死叉，不得回溯出場；必須等待未來另一個新死叉。
6. 若 2R 首次成立的同一天剛好形成新死叉，可以出場。
7. 固定防守與有效 KD 新死叉同日成立時，固定防守優先。

低 regime 的 MACD 綠翻紅進場部位完全沿用策略 A，不套用 2R/KD 規則。

## 5. 兩種完整成交版本

- `SIGNAL_CLOSE`：進場與出場都以訊號當日未還原收盤成交，僅作理想化因果對照。
- `NEXT_SESSION_OPEN`：訊號於收盤凍結，進場與出場都排到次一官方交易日未還原開盤成交，是實務主口徑。
- 不允許收盤進場、隔日開盤出場或其他混合第三版。兩版本使用相同訊號規則。

## 7. 凍結研究矩陣

- 全期、年度、固定期間。
- 滾動 3／5／10 年；資料不足必須明標，不可補算。
- regime、交易穩定度、報酬集中度。
- 20／40／60bps 成本壓力。
- A、B 各自相同的 243 組參數格：MA fast 18／21／24、MA slow 126／144／162、MACD fast 18／21／24、MACD slow 50／55／60、MACD signal 45／55／65 的笛卡兒積。KD 固定 9／9／55，門檻固定 2R，不搜尋 KD 或 R 倍數。
- 核心持有 0／20／40／60%。

上述切片與研究配置都不是新策略。正式目標是判斷規則在因果、完整成本與多切片下是否具有正期望，不是挑選單一最好看的樣本。
