```text

與規格不一致之處：

```

## 回報規則

1. 未完成也要清楚列出已完成與未完成範圍。
2. 不得用「已最佳化」取代具體規則差異與績效證據。
3. 任何未經主控允許的偏離都必須列在「與規格不一致之處」。
4. 回測必須附 `run_id` 及 manifest；程式修改必須附 commit 或完整 diff 狀態。
5. 若資料、定義或成交模型不足以支持結論，應停止並回報，不得補猜。
