# 雙均線回測固定報告格式 v2

除非使用者明確指定不同比較方式，所有正式回測一律使用本格式。

## 核心口徑

1. 同一個帳戶只在研究起始日投入一次本金，之後連續重播到資料截止日。
2. 年度統計只能從同一條連續資產曲線切片，不得在每年一月重新投入、重新建立策略狀態或強制平倉。
3. 跨年度持倉、監控狀態、已實現損益、現金及權利必須延續。
4. 尚未賣出的部位按截止日原始收盤價扣除假設賣出成本估算，與已實現損益分列。
5. 比較方法使用相同起始本金、相同期間、相同原價、相同費稅與價差口徑；不同部位配置規則必須明說。
6. 對照基準不參與策略排名。

## 長期持續監控標的的生命週期

1. 像 ETF 這類每天都在固定監控清單內、沒有重新入選事件的標的，不能把整段多年歷史誤當成單一且只能失效一次的選股事件。
2. 一段均線多頭區間結束後，下一個新的均線多頭區間必須視為新的監控週期，可重新等待完整進場訊號；停損後同一多頭區間的重新進場、同日不得賣出又買進等原規則維持不變。
3. 由每日選股事件啟動的股票策略仍沿用各自選股事件的有限生命週期，不得把 ETF 例外反向套用到股票回測。
4. 零交易的方法必須附進場機會稽核，區分「完全沒有完整訊號」與「有完整訊號，但未通過額外條件」，不可只顯示交易次數為零。

## 固定人眼報告

### 1. `report.md`

報告入口與建議閱讀順序。

### 2. `shared-account-report.md`

必須依序包含：

- 每日總資產圖。
- 先講結論。
- 五年整體成績。
- 獲利年度數、獲利年度與虧損年度。
- 從連續帳戶切出的逐年報酬、逐年最大資產回落與年底資產。
- 同年度大盤報酬與大盤最大回落。
- 年底仍持有數量、當年進場與賣出次數。
- 空頭防守及後段多頭依賴。
- 資金周轉、最高持倉成本、費稅、股利、已實現與截止估算損益。
- 回測方法、資料截止日及使用限制。

### 3. `benchmark-risk-report.md`

必須說明大盤基準、年化報酬、最大資產回落、報酬相對回落、現金閒置、2022 防守效果及 2025～2026 多頭依賴，並附回落比較圖。

### 4. `trade-details.md`

逐筆列出買進日期、投入金額、賣出或估值日期、原因、費稅後損益及獲利率；已賣出與截止日估算必須清楚區分。

## 固定機器附件

- `scenario-summary.csv`：五年總指標。
- `calendar-year-summary.csv`：連續帳戶逐年切片。
- `daily-equity.csv`：策略、對照基準與大盤的每日總資產及回落。
- `trade-details.csv`：完整逐筆交易。
- `transactions.csv`：全部買賣動作。
- `corporate-actions.csv`：股利、分割與其他公司行動。
- `benchmark.csv`：大盤報酬指數資料與來源。
- `signal-opportunity-audit.csv`：逐年及全期間完整訊號候選、實際買進與未進場原因。
- `equity-curves.svg`：每日總資產比較圖。
- `drawdown-curves.svg`：每日資產回落比較圖。
- manifest、readback、checkpoint 與獨立 QA 結果。

## 用語

- 使用「截至截止日仍持有」及「資料不足暫不列入」，不顯示內部英文狀態代號。
- 「買入周轉總額」不是外部本金。
- 「單一時點最高持倉成本」可以包含先前已實現獲利再投入，不代表追加資金或借款。
- 2026 若不是完整年度，必須在所有年度比較旁標示截止日期。
