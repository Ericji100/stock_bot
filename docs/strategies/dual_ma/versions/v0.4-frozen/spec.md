# 雙均線交易監控策略 v0.4-frozen

## 1. 文件狀態與適用範圍

- 版本：`dual-ma-v0.4-frozen`
- 狀態：`FROZEN`
- 凍結日期：`2026-09-21`
- 用途：第一輪因果回測的唯一交易規則契約
- 不允許：正式下單、正式監控、執行任務自行修改規則或挑選最佳參數

本版凍結交易邏輯與第一輪實驗矩陣。股票母體、資料期間及資料雜湊由「01 選股名單與資料凍結」交付，每次回測必須以 `universe_id` 與 `data_snapshot_id` 綁定，不得依回測績效改名單。

## 2. 共用原則

1. 中期與長期策略獨立建倉、獨立計算、獨立出場、獨立報告。
2. 同一股票可同時持有中期及長期部位，不合併成本或損益。
3. 每套策略由一筆母單及最多三筆加碼組成，最多四腿。
4. 每腿各自保存進場價、股數、初始停損、初始 `R`、成本防線及有效停損。
5. 所有訊號只使用當時已完成的日 K；不得用後續資料回填樞紐或防線。
6. 第一輪使用 `SMA`，不使用 `EMA`。
7. 均線、進出場訊號及停損判斷的相等值均不視為站上；站上使用 `>`，跌破使用 `<`，趨勢資格在快線不再高於慢線時終止。

## 3. 價格、均線與成交代理

### 3.1 均線

- `SMA5`：最近 5 個交易日收盤價的簡單移動平均。
- `SMA21`：最近 21 個交易日收盤價的簡單移動平均。
- `SMA144`：最近 144 個交易日收盤價的簡單移動平均。
- 訊號用價格序列的公司行動處理方式由資料快照固定，且同一次 run 不得切換。

### 3.2 第一輪成交代理

- 進場、加碼、結構停損、移動停利及均線退出，第一輪均以訊號日收盤價模擬成交。
- 成交模型 ID：`EOD_CLOSE_PROXY_V1`。
- 這是配合未來約 13:20 盤中監控的研究代理，不代表實際可在知道正式收盤後以同一收盤價成交。
- 報告必須揭露此偏誤，另輸出滑價敏感度，不得把代理結果宣稱為可實現報酬。

### 3.3 實際監控保留事項

- 預計 12:00 後啟動掃描，13:20 左右用分鐘價格判斷是否仍未站回條件價。
- 委託價格、未成交、部分成交、最後可委託時間及故障恢復由03監控任務在 Shadow 階段實作。
- 上述盤中流程不改寫第一輪日線回測資料。

## 4. 監控資格與基準進場

### 4.1 中期策略 `MEDIUM_SMA_5_21`

1. 已完成日 K 滿足 `SMA5 > SMA21` 才具有監控資格。
2. 在已有監控資格後，第一次出現 `close < SMA5`，建立一個拉回事件。
3. 拉回事件持續到第一個 `close > SMA5` 的完整交易日。
4. 該日產生 `ENTRY_RECLAIM_ONLY` 訊號，使用當日收盤價成交代理。
5. 拉回事件從首次跌破日至收復日的最低 `low` 為該腿初始停損參考價。

### 4.2 長期策略 `LONG_SMA_21_144`

1. 已完成日 K 滿足 `SMA21 > SMA144` 才具有監控資格。
2. 在已有監控資格後，第一次出現 `close < SMA21`，建立一個拉回事件。
3. 拉回事件持續到第一個 `close > SMA21` 的完整交易日。
4. 該日產生 `ENTRY_RECLAIM_ONLY` 訊號，使用當日收盤價成交代理。
5. 拉回事件從首次跌破日至收復日的最低 `low` 為該腿初始停損參考價。

### 4.3 事件失效與去重

- 拉回期間若快線不再高於慢線，本次拉回事件失效。
- 同股、同策略、同日只允許一個同方向成交事件。
- 已持倉後必須重新出現一段新的「跌破快線再收復快線」事件，才可能加碼。
- 快慢線剛交叉、方向衝突的 Q2／轉換反轉不另建特殊進場權限；必須先有監控資格，再完成新的拉回及收復事件。
- `ENTRY_RECLAIM_PIVOT1_CONFIRMED` 不在第一輪。

## 5. 股數、成本與初始風險

### 5.1 每腿限制

- 每腿買進總成本不得超過新台幣 10,000 元。
- 盤中零股股數為正整數且不得超過 999 股。
- 每腿估計初始風險不得超過新台幣 2,000 元。
- 若連 1 股都無法同時符合名目金額及風險限制，訊號記為 `NON_EXECUTABLE`，不得成交。

### 5.2 初始 `R`

每腿的 `R_i` 不是固定 2,000 元，而是依該腿實際模擬股數計算：

```text
R_i = shares_i * (entry_price_i - initial_stop_i)
      + estimated_buy_commission_i
      + estimated_stop_exit_commission_i
      + estimated_stop_exit_tax_i
      + configured_slippage_buffer_i
```

- 必須滿足 `0 < R_i <= 2000`。
- 2,000 元是每腿風險上限，不是每套策略或每檔股票的總風險上限。
- 母單加三次加碼的名目風險上限為每套策略 8,000 元；中期與長期同時持有時須另行報告合計曝險，不在本版新增跨策略上限。

### 5.3 股數演算法

從 999 股與名目金額可容納股數的較小者開始，向下尋找最大整數 `q`，使：

```text
q * entry_price + buy_commission <= 10000
estimated_R(q) <= 2000
```

此規則的優先順序是「不超過限制」，不是強迫每腿一定投入滿 10,000 元。

### 5.4 基準交易成本

- 網路下單買賣手續費率：成交價金的 `0.399‰`。
- 股票賣出證券交易稅：成交價金的 `0.3%`。
- ETF／受益憑證賣出證券交易稅：成交價金的 `0.1%`；其他商品依資料分類及當期法規另列。
- 基準滑價：`0 bps`，並強制輸出每邊 `10 bps`、`20 bps` 的敏感度結果。
- 金額進位與最低手續費必須由成本模型 ID 明示；若無法取得使用者實際對帳單規則，基準採逐筆元級計算且不得聲稱與實際帳單完全相同。

成本模型 ID：`CATHAY_WEB_028_TW_V1`。

## 6. 加碼比較組

所有加碼共同要求：

1. 新的獨立拉回與收復事件成立。
2. 同日訊號已去重。
3. 該套策略尚未達三次加碼上限。
4. 新腿依自己的拉回低點建立初始停損及 `R_i`。
5. 新增部位不得放寬任何既有腿的有效停損。

### 6.1 `ADD_R1_AGGREGATE`

在加碼訊號日收盤，以假設立即賣出所有開放腿後的淨損益計算：

```text
aggregate_unrealized_net_pnl >= sum(initial_R_i of all open legs)
```

只有條件成立才新增一腿。加碼成交後，新腿的 `R_i` 才加入下一次門檻。

### 6.2 `ADD_SIGNAL_ONLY`

- 只檢查共同要求，不設目前損益或 `R` 門檻。
- 即使整體部位正在虧損，新訊號仍可新增一腿。
- 本組是研究對照，不代表正式監控建議。

## 7. 每腿結構停損

1. 每腿初始停損為該腿進場事件的 `pullback_low`。
2. `close < effective_stop_i` 才確認該腿停損；`close == effective_stop_i` 不退出。
3. 第一輪按確認日收盤價成交，而不是假設可按停損參考價成交。
4. 各腿分開停損；某腿退出不自動關閉其他腿。
5. 有效停損只可維持或提高，絕不可降低。

## 8. 日線道氏防線

### 8.1 樞紐參數

- 第一輪固定 `n=2`，即左右各需要 2 根完整日 K。
- 樞紐必須等右側第 2 根日 K 完成後才可使用。
- 相等高低點視為一個等價區，不任意挑選其中一根；防線價使用該區共同極值，確認時間不得早於等價區結束後第 2 根完整日 K。

### 8.2 多方防線成立

1. 先有一個當時已確認的樞紐高點。
2. 之後形成並確認候選樞紐低點。
3. 候選低點之後的收盤價突破前述樞紐高點。
4. 只有在突破收盤完成後，候選低點才升格為有效多方道氏防線。
5. 單純形成較高低點但尚未突破前高，不得提前移動防線。
6. 新防線只在價格高於舊防線時取代；防線不得下降。

## 9. 停利與出場比較組

三組都保留第7節每腿結構停損，以及第10節均線趨勢終止。

### 9.1 `EXIT_DOW_TRAIL`

```text
effective_stop_i = max(initial_stop_i, latest_confirmed_daily_bull_defense)
```

- 不使用 2R 成本防線。
- 收盤跌破各腿有效停損時，該腿出場。

### 9.2 `EXIT_2R_DOW_TRAIL`

每腿以自己的初始 `R_i` 判斷。若某日收盤按立即賣出估算的該腿淨浮盈曾達 `2 * R_i`，該腿永久啟動成本防線：

```text
effective_stop_i = max(
  initial_stop_i,
  breakeven_price_including_round_trip_cost_i,
  latest_confirmed_daily_bull_defense
)
```

- 達 2R 不直接賣出。
- 成本防線與道氏防線都只升不降。

### 9.3 `EXIT_2R_21MA_2CLOSE`

1. 每腿仍以自己的 `R_i` 判斷 2R；達 2R 的腿將最低保護提高到含來回成本的損益兩平價。
2. 當全部開放腿的淨浮盈曾達其初始 `R_i` 總和的 2 倍，啟動本策略波段的 21MA 雙收盤停利。
3. 啟動後，第一次 `close < SMA21` 記為 `EXIT_WARNING`。
4. 下一個交易日若仍有 `close < SMA21`，以該日收盤價退出本策略全部開放腿。
5. 若中間任何一日 `close >= SMA21`，連續計數歸零。
6. 本組不使用道氏防線作移動停利，但每腿原始結構停損、已啟動的成本防線及均線趨勢終止仍有效。

「二次跌破」固定指連續兩個交易日收盤低於當日 SMA21，不是累積第二次盤中跌破。

## 10. 均線趨勢終止

- 中期：完成日 K 出現 `SMA5 <= SMA21`，當日收盤出清全部中期腿並停止中期監控。
- 長期：完成日 K 出現 `SMA21 <= SMA144`，當日收盤出清全部長期腿並停止長期監控。
- 直到重新滿足快線高於慢線，才可重新進入監控；仍必須完成新的拉回及收復事件才能進場。
- 同日同時滿足多個出場原因時，成交價相同，原因標籤優先序為：`STRUCTURAL_STOP`、`PROFIT_EXIT`、`REGIME_EXIT`。

## 11. 第一輪回測矩陣

固定進場、停損、部位與成本，只比較下列 6 組：

| 組別 | 加碼 | 出場 |
|---|---|---|
| `M1` | `ADD_R1_AGGREGATE` | `EXIT_DOW_TRAIL` |
| `M2` | `ADD_R1_AGGREGATE` | `EXIT_2R_DOW_TRAIL` |
| `M3` | `ADD_R1_AGGREGATE` | `EXIT_2R_21MA_2CLOSE` |
| `M4` | `ADD_SIGNAL_ONLY` | `EXIT_DOW_TRAIL` |
| `M5` | `ADD_SIGNAL_ONLY` | `EXIT_2R_DOW_TRAIL` |
| `M6` | `ADD_SIGNAL_ONLY` | `EXIT_2R_21MA_2CLOSE` |

中期與長期必須分開統計，再額外提供合併資金占用視圖；不得只交付合併績效。

## 12. 回測輸出契約

每次 run 必須保存：

- `run_id`、策略版本、Git commit、`universe_id`、`data_snapshot_id`、資料期間及雜湊。
- 股票代碼、商品類型、中期／長期、矩陣組別、episode 及 leg 編號。
- 訊號日、成交日、成交代理價、股數、初始停損、有效停損歷程、初始 `R_i`。
- 每次加碼的獨立拉回事件、加碼門檻計算值及允許／拒絕原因。
- 2R 啟動日、成本防線、道氏樞紐確認日／突破日／防線版本、21MA 警戒計數。
- 毛損益、手續費、交易稅、滑價情境、淨損益及退出原因。
- 不可成交、缺值、停牌、漲跌停、公司行動及資料不足事件。

報告至少包含交易數、勝率、平均與中位數 R、期望值、盈虧比、Profit Factor、總淨利、最大回撤、曝險時間、尖峰名目資金、尖峰估計風險、年度分組、商品類型分組、成本及滑價敏感度。

## 13. 明確不在本輪的項目

- 收復均線後等待參數1樞紐才進場。
- 慢線結構完全型態停損。
- 慢線斜率過濾。
- Q2／轉換階段反轉。
- 左右戰法加 MACD 背離反轉。
- ATR 移動停利、N 日低點停利、均線加結構混合停利、分批停利。
- AI 看圖自由裁量、績效解封後修改同一批規則再宣稱樣本外有效。
