# v0.4.1-frozen 變更紀錄

## 2026-09-22

- 本版僅釐清 `v0.4-frozen` 的狀態生命週期與腿數上限，不改變六組實驗矩陣。
- 「最多四腿」改以同一個 episode 的累計建立腿數計算；已退出腿仍占用該 episode 名額，必須等全部腿結束並開始新 episode 才重置。
- 中期與長期策略各自維護一條有效的道氏防線生命週期。
- 收盤嚴格跌破有效道氏防線時，該防線先供當次出場使用，之後失效。
- 快線不再高於慢線、策略所有腿結束或 episode 結束時，該策略的道氏防線失效。
- 新 episode 必須等待新的合格「樞紐低點後突破已確認樞紐高點」事件；新生命週期的第一條防線可低於前一個已失效生命週期。
- 新腿不得繼承高於其成交價的舊防線；遇到此狀況必須使舊防線失效並留下稽核紀錄。
- run manifest 明列規格雜湊、矩陣、成交代理、成本及滑價，且必要識別欄位不得為空。
