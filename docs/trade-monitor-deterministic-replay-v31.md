## 結論

v31已達成「相同資料、相同程式與相同規則版本，產生相同交易事實」。AI模型、AI措辭及取樣差異不再決定定錨、道氏防線、象限、戰法資格、進場、停損、管理或出場。

```powershell

python -m trade_monitor_replay.performance <RUN_DIR> --fee 12 --slippage 1
python -m trade_monitor_replay.reproducibility <RUN_DIR_A> <RUN_DIR_B>
```

只有`reproducibility`回傳`status=identical`才能視為同版本重現成功。

## 未來換AI模型的驗收

1. 先以相同原始資料、manifest、execution version及程式碼重跑`--program-only`。
2. 程式fingerprint必須與基準完全相同；不同即停止，不得比較AI文字來宣稱相同。
3. AI只能讀封存後的程式狀態生成卡片；使用schema與語意驗證拒絕任何改價、改方向、改setup或改action的輸出。
4. 模型更新只需做文字正確性、繁體中文、Telegram長度及不得洩漏未來資料的評估；不重新授權模型決定交易。
