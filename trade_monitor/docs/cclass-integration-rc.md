# 戰法 C 班整合 RC：單一交易系統對照

版本：`enlightenment-integrated-v1.8-cclass-rc-shadow`（未部署）

## 核心設計

戰法 C 班不是獨立監控層，也不和既有規則投票。每輪只保留一個市場狀態與一個工作看法：

`因果樞紐／防線／定錨 → 有序或無序 → 太極或一之唯一主模式 → 號盤／象限 → 原四型態 → 停損／R／一口管理 → 九欄通知`

## 太極如何接入

| 太極段序 | 系統用途 | 可以做什麼 | 不能做什麼 |
|---|---|---|---|
| ANCHOR_1 | 建立朝代、方向與比較父代 | 建立背景與失效條件 | 單靠第一段追價 |
| CORRECTION_2 | 第一次修正 | 映射趨勢拉回延續的準備區 | 只因叫第 2 段就進場 |
| COPY_3 | 複製第 1 段 | 五維品質合格時維持趨勢看法 | 複製弱就立即反手 |
| CORRECTION_4 | 修正第 3 段 | 再次映射趨勢拉回延續 | 破壞父代後仍視為正常拉回 |
| COPY_5 | 複製第 3 段 | 評估末段延續與保護 | 把第 5 段當必然反轉 |
| POST_5 | 延長、級數升級或重置 | 停止追價、等待新結構 | 事後硬數波浪改寫當時判斷 |

每次複製／修正都保留五項，而不是只比點數：幅度、時間、斜率、乾淨度、結構破壞性。綜合品質只用 `STRONG／ACCEPTABLE／WEAK／FAILED／UNKNOWN`；不捏造精確分數。

## 一之如何接入

| 一之階段 | 系統用途 | 映射的原型態 |
|---|---|---|
| CENTRIFUGAL_FORMING／CONFIRMED | 辨識異常加速與 Q1 動能品質 | OR 突破回踩，或等待後續拉回；本身不進場 |
| DRAGON_EARLY／MIDDLE／LATE | 管理連續性、追價風險與保護 | 已由原型態進場的一口管理 |
| LIFE_DEATH_GATE_FORMING／ARMED | 強推進後的換手與左右力量 | 趨勢拉回、盤中壓縮，或外圍假突破反轉 |
| EXHAUSTION_WARNING／FAILED | 停止追價、降級或退出 | 不直接產生反向交易 |

離心力、一條龍、生死門都不是第五種型態。課程舊年月的固定分鐘／點數只留作研究線索，現行監控使用相對波動與因果結構；無停損、核爆滿倉、多口牡丹不納入。

## 看法何時改變

- **維持**：定錨、防線與父代結構有效；複製／修正或動能品質仍合格。
- **降級**：複製轉弱、修正拖長、一條龍進入中後段、樞紐壓力增加；停止追價但方向未失效。
- **中立**：複製失敗且變成更大修正、同級防線破壞、動能收回發動區或定錨過時；取消原方向候選但不反手。
- **正式翻向**：原方向有效防線破壞、反向錨因果確認、反向慣性延續，並優先等待第一次右左再發動。

## 九欄通知如何呈現

- **當前趨勢**：目前太極第幾段，或一之動能方向／階段。
- **市場狀態**：有序／無序、唯一主模式、號盤、象限與位置。
- **觀察型態與狀態**：仍只寫原四型態，附太極品質或生死門映射理由。
- **尚缺條件／觸發**：工作看法的維持、降級、中立、翻向條件，以及原型態尚缺的收盤行為。
- **單口管理／禁止原因**：動能早中末段、太極複製失敗、時間／行為失效與不可追價原因。

完整段序、五維比較、動能 episode 與看法條件保存在內部 `cclass_context`。使用者只看影響當下決策的摘要；這是輸出精簡，不是規則刪除。
