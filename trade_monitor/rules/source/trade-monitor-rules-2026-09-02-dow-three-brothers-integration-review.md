## 結論

道氏三兄弟可以補強現行監控最薄弱的部分：**何謂有效高低點、哪個波段才有資格成為防線，以及反轉從警告到可執行要經過哪些結構階段**。

但不應把道氏、樞紐、左右戰法另外做成三個監控模組。較一致的做法是直接改寫現有判斷鏈：

```text
已收盤 1 分 K
→ 更新樞紐生命週期
→ 判斷一級／二級道氏結構與防線
→ 分類延續、Type 1／2／3 或級數升級
→ 形成既有大趨勢／當前趨勢與號盤
→ 用象限、S／S／T／V篩選原有四種型態
→ 以左左／左右／右左／右右描述同一型態的成熟度
→ 檢查觸發、憲法、停損、R、障礙與一口單管理
→ 仍以原九欄輸出
```

這樣整合後，原有四種型態仍是唯一的進場型態；課程概念只負責把方向、失效與成熟度定義得更精確。

## 一、現行規則已經相同的部分

| 現行規則 | 道氏三兄弟對應 | 整合決定 |
|---|---|---|
| 只以已收盤 1 分 K 確認 | 樞紐右側確認與防線突破不能事先知道 | 保留，且樞紐低／高被突破也收緊為收盤確認 |
| 最近 K 高低點推進 | 道氏的高過高／低不破低、低破低／高不過高 | 改用已確認樞紐客觀化，不再完全靠目視 |
| 1 分觸發、5 分結構、15 分脈絡 | 一級、二級與大週期濾網 | 保留同一多級架構，不另產生共振答案 |
| 大趨勢與當前趨勢分開 | 大級防線與小級慣性不能混淆 | 保留；大趨勢寫二級／5、15 分，當前趨勢寫一級 |
| 最後防守波段失守才考慮翻向 | 道氏防線突破 | 保留概念，但必須收緊防線資格 |
| 有效翻向需突破、守住、結構轉向 | Type 2 先破防線再完成反向慣性 | 直接合併成同一翻向規則 |
| 逆大趨勢訊號先觀察 | Type 1 只是警告 | 保留並明確禁止左左／左右直接反手 |
| OR／趨勢拉回需等回踩再發動 | 右左後右右 | 保留原型態名稱，只補上成熟度標籤 |
| 不追價，停損放完整拉回極值外 | 右左以拉回極值失效、右右不應忽略風險 | 保留並補充右右停損不能只貼突破 K |
| 一口、不攤平、不加碼 | 課程風險仍應受總額度限制 | 現行一口規則優先，不採四份配置 |
| 結構轉換影響持倉退出 | 道氏防線可作動態退出依據 | 整合到既有持倉管理，不另做出場系統 |

## 二、名稱相近但必須調整的部分

### 1. 「最後防守波段」不能等於任意支撐壓力

現行有效翻向允許使用「最後防守波段、原突破失效點、OR 對側或其他明確邊界」。這對一般圖形監控夠彈性，但與課程的道氏防線不是同一件事。

整合後：

- 多頭防線只能是「從該同級樞紐低點發動，之後確實造成同級創高」的低點。
- 空頭防線完全鏡像。
- 只出現較高低點／較低高點，尚未創高／創低時，防線不能提前移動。
- OR、箱頂底與時段高低仍可作型態邊界；只有符合上述因果關係時才兼具道氏防線資格。
- 時段初期樞紐不足時，OR 對側只能標為「暫代失效邊界」，不能假稱正式防線。

這是本次最重要的修正，因為它能避免監控為了貼近現價，不斷把防線移到尚未被市場證明的點。

### 2. 「有效翻向」要拆成警告、確認與急變

| 課程分類 | 與現行規則關係 | 整合後動作 |
|---|---|---|
| Type 1 | 現行的短線轉弱／轉強或反向候選 | 只警告；大防線未破，不增加號盤、不建立逆向模擬倉 |
| Type 2 | 最接近現行有效方向翻轉 | 防線破後仍要完成反向樞紐慣性，才翻向並增加號盤 |
| Type 3 | 現行沒有獨立定義 | 同一推進穿越小、大防線時高優先通知；舊方向處理風險，新方向不追、等右左 |
| 級數升級 | 現行可能被誤判成假訊號 | 保留原判斷歷史，從新事件起升級級數，不用事後重畫掩蓋錯誤 |

### 3. 「高低點」要有即時生命週期

課程樞紐會延遲，也會在相反樞紐形成前被更極端點取代。如果回測直接使用事後畫好的全部樞紐，會偷看到未來。

整合後固定使用：

```text
候選 → 局部成立 → 配對確認
                ↘ 失效／被更極端點取代
```

每個監控回合只能使用當時已知狀態。最新點若仍可能重畫，只能寫「候選／局部成立」，不能用配對確認後的結論倒填前幾分鐘。

### 4. 「左右戰法」不是第五種進場型態

現行監控已有四個型態，左右戰法實際描述的是反轉從猜測到確認的位置。因此整合為同一型態的成熟度：

| 原有型態 | 左右成熟度如何嵌入 |
|---|---|
| 開盤區間突破回踩 | OR 突破後第一次回踩守住＝右左；再發動＝右右 |
| 趨勢拉回延續 | 已成立趨勢中的拉回＝右左；突破拉回小區間＝右右 |
| 盤中壓縮突破 | 原防線未破的逆向小箱突破最多是左右；新方向確認後的回踩／再突破才是右左／右右 |
| 假突破／假跌破反轉 | 收回邊界可形成左左／左右線索；原防線未破不得反手，防線破後等右左才優先執行 |

## 三、本次新增的正式定義

### 1. 一級樞紐起始參數

- 草案固定 `n=2`，因為一分鐘監控需要兼顧反應速度與雜訊；課程只說日線以下常用 2～3，並沒有證明台指一分 K 的最佳值。
- 左側兩根條件成立時只能先標「潛在候選」；局部成立前，右側兩根也必須是完整已收盤 K，候選 K 自己不能算入。
- 高點候選除左右條件外，候選 K 低點還要被後續 K 收盤跌破才局部成立；低點鏡像。
- 使用「收盤突破」比課程單純「突破」更保守，是為了符合現有監控一律用收盤確認的資料紀律。
- 相等高低點先當極值區，不任選一根；無唯一極值時標示樞紐未定。

`n=2` 是待驗證規格，不是已證實優勢。正式切換前應至少比較 `n=2` 與 `n=3` 在日／夜盤、第一小時與一般時段的差異。

### 2. 二級樞紐與既有 5／15 分脈絡

- 二級點只從已確認一級點再篩選，依課程固定 `n=1`。
- 二級樞紐不另開一個監控層；它直接成為大趨勢的結構證據。
- 合成 5／15 分 K 繼續保留，作為時間框架交叉檢查。
- 二級樞紐與 5／15 分結構矛盾時，標「結構不一致／轉換中」，不得挑對持倉最有利的一方。

### 3. 比例原則的保守處理

課程主張刪除不成比例的小樞紐，但沒有公式。若讓 AI自行決定哪些點太小，會產生不可重複的結果。

因此草案只標示「微型樞紐／比例疑慮」，並限制它不能單獨：

- 更新正式道氏防線。
- 增加號盤。
- 完成逆大趨勢進場。

正式量化前不直接刪點。日後可回測 ATR 正規化振幅、相鄰波段中位數比率、持續 K 數與最小間隔，再決定唯一公式。

### 4. 一口單可執行成熟度

| 階段 | 一口單規則 |
|---|---|
| 左左 | 觀察，不進場 |
| 左右 | Type 1／小級確認，最多條件式，不反手 |
| 右左 | 防線已破後第一次有效拉回，優先可評估階段 |
| 右右 | 延續確認；只有位置未過遠、停損與障礙合理時才可評估 |

這項決定犧牲課程左側早期價格，換取與現行 0 號導向、收盤確認及一口單風控的一致性。

## 四、號盤與道氏反轉的合併規則

現行號盤不另外保留一套翻向定義，而改為：

1. 0 號方向仍由 OR 或重要結構的已收盤突破建立。
2. Type 1 不增加號數。
3. 防線被破先標「轉換中」。
4. Type 2 完成且當前趨勢翻向，號數加一。
5. Type 3 穿越小、大防線且當前趨勢翻向時可加一，但新方向等右左，不追第一段。
6. 影線、兩根內收回、箱體中央來回與比例疑慮微型點不計號數。
7. 級數升級不能倒扣已發生的號數；它是當時可得資訊下的歷史狀態。

## 五、持倉與停損如何調整

- 原有四型態的結構停損仍保留。
- 右左停損放在防線突破後第一次完整拉回／反彈極值外，再加既有緩衝。
- 右右原則上沿用右左整段極值，不能只貼突破 K；太遠就不追，等下一個右左。
- Type 1 對舊持倉是風險警告，不等於自動反手；依原型態失效、時間失效與既有保護規則決定退出。
- Type 2 使原方向候選失效，仍持有原方向時提示退出；新方向等待右左。
- Type 3 優先處理舊方向風險，新方向同樣不追。
- 防線只有在新同級創高／創低後才能更新，不能用未取得資格的樞紐過早縮緊停損。

## 六、刻意不納入的內容

| 課程內容 | 不納入原因 |
|---|---|
| 左左、左右、右左、右右各一份 | 現行明確是一口單，沒有總風險與多口 schema |
| Type 3 直接進右側時一次補足兩份 | 快速 V 轉通常波動、滑價與停損距離更大，與一口、不追價衝突 |
| 順勢加碼 | 現行禁止虧損加碼，且沒有多口總風險設定 |
| 講師口述各階段勝率 | 沒有資料集、樣本數與獨立回測，不可寫入模型門檻 |
| 第三次攻擊／第五波直接摸頭底 | 只能作趨勢後段背景，不能取代樞紐、防線與收盤觸發 |
| 心理敘述直接觸發 | 心理無法由截圖客觀觀測，只能作解釋文字 |
| 技術背離單獨觸發 | KD、MACD與跨市場背離仍只作輔助，不能取代價格結構 |
| 日線只做單向濾網 | 現有資料源是遠端 1 分 K 圖，沒有可靠日線狀態、換月與夜盤歸日規格 |
| 任意刪除「比例太小」樞紐 | 尚無量化公式，先標疑慮，不假裝唯一答案 |

## 七、輸出與程式相容性

本草案不修改 `trade-monitor-analysis-v2`：

- `large_trend.details`：二級樞紐、5／15 分結構與大級防線。
- `current_trend.details`：一級樞紐、5～20 分方向與小級防線。
- `market_state`：時段、號盤、象限、波動與位置。
- `pattern_observation.details`：原四種型態、S／S／T／V、Type 與左右成熟度。
- `missing_conditions_or_trigger`：尚缺的樞紐、防線、回踩或再突破條件。
- `entry_and_structural_stop`：右左／右右的進場評估與結構失效。

Type 與左右成熟度是 details 內容，不新增 enum，也不新增第十欄。若項目超過 schema 上限，合併同類資訊，但失效與禁止原因不能省略。

## 八、正式切換前必須驗證

1. **樞紐參數**：比較 `n=2`、`n=3` 的訊號延遲、密度、重畫率與 Type 1 假警告率。
2. **收盤確認**：比較候選 K 高低的盤中穿越與收盤穿越，確認保守化是否錯失過多機會。
3. **比例公式**：先保留標註，再從歷史案例選出可重複門檻。
4. **Type 2／Type 3**：逐筆檢查大小防線是否在當時已成立，不能用事後線段回填。
5. **右左優先**：分別統計右左與右右的停損距離、第一障礙空間、勝率與期望值。
6. **分時段**：日盤、夜盤、開盤前 30 分鐘與一般時段分開看，避免平均值掩蓋差異。
7. **完整績效**：至少檢查交易筆數、勝率、平均盈虧比、期望值、獲利因子、最大回撤、連續虧損與成本／滑價敏感度。
8. **前向模擬**：歷史與樣本外通過後，先維持模擬監控，不因課程邏輯完整就直接視為可實盤系統。
