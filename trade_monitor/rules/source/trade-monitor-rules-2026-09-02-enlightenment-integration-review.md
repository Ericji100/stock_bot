# 台指期 1 分 K 監控規則 × 啟蒙交易課程｜整合評估

- 評估日期：2026-09-02
- 現行來源：Automation `1-k` 實際啟用提示詞
- 現行狀態：`PAUSED`
- 本文件用途：說明哪些規則保留、哪些調整、哪些補充，以及整合決策的原因
- 完整整合版：`trade-monitor-rules-2026-09-02-enlightenment-integrated.md`

## 結論

現行規則已具備課程約大部分的骨架：多級數脈絡、順勢原則、箱型中央禁止、結構停損、不得追價、等待確認、一口單管理與交易後檢討都與課程一致。

真正需要補入的不是另一套獨立分析，而是修改既有三個判斷：

1. 在「市場狀態」內加入**號盤**，讓方向反轉次數成為原有大趨勢／當前趨勢的約束。
2. 把原本單一的「盤整」拆成**四象限狀態**，決定四種既有型態何時可以使用。
3. 把 S／S／T／V 直接納入原有開盤區間與盤中壓縮型態的**品質准入條件**。

整合後仍是同一條判斷流程、同一組四種型態、同一份九欄通知，不會增加一份平行的「課程監控結果」。

## 一、現行規則與課程相同、直接保留的部分

| 現行規則 | 課程對應 | 決定 |
|---|---|---|
| 只以已收盤 1 分 K 確認訊號 | 交易必須有明確、可重複的確認點 | 保留 |
| 1 分 K 執行，合成 5 分／15 分脈絡 | 掌握日內最大級數及其下 1～2 個次級架構 | 保留 |
| 大趨勢與當前趨勢分開 | 大級數架構與次級架構不能混為一談 | 保留 |
| 大趨勢偏多時等待回檔重新轉多，反之亦然 | 0 號導向、順勢交易 | 保留，並正式命名為預設 0 號風格 |
| KD、MACD 不得單獨觸發 | 分析必須轉成完整進出場策略 | 保留 |
| 箱型中央禁止交易 | 箱型必須評估位置與 CP 值 | 保留 |
| 不追價、等待第一次或第二次回踩 | 等待機會、進場位置影響後續判斷 | 保留 |
| 結構停損，不用任意固定點數取代失效點 | 下單前後一定要設停損 | 保留 |
| 未知真實成交時只能稱模擬持倉 | 不虛構執行結果 | 保留 |
| 趨勢單與盤整／假突破單採不同出場 | 動能的錢與趨勢的錢要用不同方式處理 | 保留 |
| 每個原始型態最多重新進場一次 | 避免過度交易 | 保留，另加入全時段總次數限制 |
| 交易後檢討不以結果倒推對錯 | 對的交易仍可能虧損；違規獲利仍是錯誤 | 保留並擴充 |
| 圖表資訊不足時不得杜撰 | IT／資料品質是交易優勢的一部分 | 保留 |

## 二、名稱相似但實際不同，必須調整的部分

### 1. 開盤區間不等於號盤

現行 OR5／OR15 是開盤箱型與突破觸發；課程的號盤則是記錄本時段已出現幾次有效方向轉換。兩者用途不同：

- OR5／OR15：提供邊界、突破、回踩與停損位置。
- 號盤：限制今天應專注一個方向、允許一次翻向，或在多次翻向後停止追趨勢。

整合決定：保留 OR5／OR15，另把號盤寫進原本的「市場狀態」，但號盤不獨立產生進場訊號。

### 2. 原本的盤整必須拆成第二與第三象限

現行盤整規則將「趨勢性低」視為同一狀態，但課程區分：

- 第二象限：趨勢性低、波動率高，屬劇烈轉換或雜訊盤。
- 第三象限：趨勢性低、波動率低，才是可等待壓縮突破的盤。

整合決定：保留原有盤整三項判斷，增加波動率判斷。高波動盤整不得再使用一般壓縮突破；低波動盤整才可評估合格箱型。

### 3. 第一與第四象限都可能有趨勢，但進場方式不同

- 第一象限：趨勢高、波動擴張，優先突破、開盤區間延續及動能型處理。
- 第四象限：趨勢高、波動收斂，優先拉回、低接／反彈與較耐心的趨勢管理。

整合決定：原本的「強勢偏多／偏空」分類繼續保留供 schema 使用；象限寫在同一個市場狀態內，直接決定四種既有型態的可用性。

## 三、課程可補充、現行規則缺少的部分

### 1. 號盤狀態

新增 `號盤未定、0 號盤向上／下、1 號盤向上／下、2 號盤以上`。只有有效結構翻向才增加號數；均線短暫穿越、單根影線或兩根內收回的假突破不計數。

用途：

- 0 號盤：順第一個方向的突破與拉回優先。
- 1 號盤：只有完成大趨勢轉換確認，才允許新方向成為主要方向。
- 2 號盤以上：原則上禁止追趨勢，只保留明確外圍邊界的假突破反轉，或觀望。

### 2. 四象限准入矩陣

新增象限不是增加第五種型態，而是決定原有四種型態能不能用：

| 象限 | 優先型態 | 降級／禁止 |
|---|---|---|
| 第一象限 | 開盤區間突破回踩、同向壓縮突破、趨勢拉回延續 | 逆勢假突破反轉降級，除非象限與大趨勢已轉換 |
| 第二象限 | 明確外圍邊界的假突破／假跌破；等待新方向確認 | 一般趨勢拉回、一般壓縮突破禁止 |
| 第三象限 | 合格箱型的壓縮突破；外圍假突破 | 箱體中央、品質不足的突破禁止 |
| 第四象限 | 趨勢拉回延續、同向壓縮後再發動 | 遠離結構的動能追價禁止 |

### 3. 箱型 S／S／T／V

直接用在 OR5／OR15 與盤中壓縮突破：

- S（尺寸／級數）：區間寬度是否適合結構停損，最近障礙是否留下足夠空間。
- S（穩定度）：收盤是否大多留在邊界內、影線是否反覆刺穿、K 棒是否乾淨。
- T（趨勢性）：前置方向、號盤及象限是否支持預定突破方向。
- V（波動率）：是否收斂或穩定，而非大小 K 棒交錯失控。

為配合純截圖讀圖，不採看似精確但無法可靠取得的 1～5 分；改為「合格／警戒／不合格」。這仍保留課程四面向，但不製造虛假精度。

### 4. 交易憲法狀態

新增但只在同一個「單口管理／禁止原因」欄位執行：

- 單一原始型態最多重進一次。
- 每個期交所交易日（前一日夜盤至當日日盤）合併最多三次模擬進場，不能夜盤、日盤各算三次；若使用者回報真實交易，真實與模擬分開計數。
- 連續三次停損或違規後，停止新進場至少 30 分鐘；冷卻時間到期後仍須重新辨識定錨、號盤與象限，不能只因時間到了就返場。
- 虧損中不得建議加碼或放寬停損。
- 不讀取帳務資料；若未提供風險預算與商品規格，只回報點數風險與 R，不推算口數。

課程中的 1%、2.5～3%、5%、10%、20% 是示範值，不能在沒有帳戶條件與使用者確認時直接寫入自動監控。

### 5. 變盤與時間出場

現行規則已有 5 分 K 結構移動停損，但缺少課程的「變盤為最後出場點」及時間失效概念。

整合決定：

- 號盤有效翻向、象限由趨勢象限轉成第二象限，且 5 分 K 關鍵結構失守時，提示原趨勢單退出。
- 進場後 3～5 根已收盤 1 分 K 沒有出現有利推進，且重新收回觸發區，提示「時間／行為失效可評估退出」；時間本身不是唯一停損理由。

### 6. 復盤欄位

交易後檢討新增：

- 當時號盤、象限、箱型 S／S／T／V 品質。
- 是否符合預設 0 號導向或已確認的 1 號翻向。
- 是否違反交易憲法或個人風格。
- 方向、進場、停損、出場分開評估，不因盈虧互相抵銷。
- 日後可彙總勝率、盈虧比、獲利因子、最大回撤、交易筆數與不同號盤／象限的績效；單次圖表回顧不虛構這些統計。

## 四、刻意不納入本版的課程內容

### 多口母單與兩次加碼

現行監控明確採一口單管理，也不讀取實際帳務持倉。若直接加入母單與加碼，系統會在不知道真實部位與風險預算時產生不安全建議。

因此本版只加入「虧損不得加碼」。未來只有在使用者明確啟用多口模式、提供最大總口數／總風險，且結構化輸出 schema 同步修改後，才能加入母單與最多兩次順勢加碼。

### 課程風險百分比

保留為個人交易憲法的參考，不直接部署。監控仍以結構停損、點數風險與 R 為核心。

### 第二象限的一般逆勢拉回

課程簡報將第二象限與逆勢拉回相連，但現行系統的資料來源是可能延遲的遠端 1 分 K 截圖。為避免將高波動轉換盤變成頻繁摸頂摸底，本版只允許原有的「明確邊界假突破／假跌破反轉」作為第二象限的保守實作。

## 五、整合後的單一決策順序

```text
最新已收盤 1 分 K
→ 更新 5／15 分脈絡與大趨勢／當前趨勢
→ 在同一市場狀態中確認時段、號盤、象限與必要的箱型品質
→ 依象限與號盤篩選原有四種型態
→ 確認已收盤 K 的觸發、失效與不追價條件
→ 檢查交易憲法、結構停損、R與最近障礙
→ 管理模擬／使用者回報持倉
→ 使用既有九欄格式與既有通知決策輸出
```

不是：

```text
原規則先產生答案
→ 課程再另外產生四象限／號盤答案
→ 人工處理兩套答案衝突
```

## 六、實作相容性

- 現行 `trade_monitor_analysis_schema.json` 不需增加欄位。
- 號盤、象限與 S／S／T／V 放入既有 `market_state` 與 `pattern_observation.details`。
- 交易憲法狀態放入既有 `single_contract_management_or_prohibition`。
- 現有固定九欄 Markdown、Telegram canonical message、event ID、resume guard、快速模式與結構化 adapter 都能保持不變。
- 本次只產出草案檔，沒有修改 Automation `1-k`，也沒有啟動監控。
