# X 戰法班整合審查

## 結論

X 課程最適合被整合為「一條盤中決策鏈」，而不是第五種型態或另一份投票答案。現行 v1.8 已經有定錨、道氏防線、太極／一之、四象限、原四型態、風險與一口單管理；X 的價值在於規定這些工具何時出場、先看什麼、何時換主鏡頭，以及進場後應期待什麼。

## 課程概念與現有規則的對應

| X 課程概念 | 整合位置 | 正式語意 |
|---|---|---|
| 前收／現貨開盤跳空 | 開盤證據 | 需權威現貨資料；期貨只能標代理，沒有來源就不可用 |
| 期貨開盤第一方向 | 開盤證據＋初始錨 | 同向／反向只調整品質，不單獨翻多翻空 |
| 09:00 前 K 棒好壞 | 開盤品質 | CLEAN／MIXED／NOISY／OVERHEATED 質性分類 |
| 第一次 DH／DL 真／假突破 | 第一次端點樣本 | 固定首次事件與首次可分類時間，只影響當日風格品質 |
| 兩腳、三腳、四腳後換工具 | 主鏡頭 | 少於兩腳開盤證據；2～3 腳太極；4 腳以上四象限；異常動能一之 override |
| 家族 DNA | 同朝代結構比較 | 一致／改變／破壞／不可用，改寫看法維持或降級 |
| 同象限、小一象限、複製修正 | 三項共振 | 候選品質加權，不繞過原四型態 |
| 黃金五腳 | 太極 1～5 段 | 保留因果腳數與 COPY_3／COPY_5，不把名稱當進場 |
| A／B／C | 機會品質 | 勝率證據×賠率證據的質性矩陣，不輸出虛假百分比 |
| 行情應有行為 | 一口單管理 | 進場前固定 expected behavior、等待根數與行為失效 |
| 啄木鳥／回本場 | 受限風險處理 | 只限已封頂 A 候選的首次有效回復退出，不加碼或攤平 |

## 不納入

- 固定年份／商品點數門檻與精確勝率宣稱。
- 沒有五檔資料時的委託簿推論。
- 巨量集中風險、核爆滿倉、無停損牡丹、多口母子單。
- 尚未形成完整、可驗證規則的反擊內容。
- 任何第五種 setup、第十欄或先產生舊答案再追加 X 答案的平行架構。

## 資料與因果限制

- 純期貨截圖不能驗證現貨前收／現貨開盤，必須保持 `UNAVAILABLE`。
- 日內高低只能用當時已知值；不能拿盤後 Day High／Low 改寫第一次端點。
- v4→v5 只可加入空 X 狀態；首次看見、首次分類與主鏡頭變更都必須由升級後新 K 因果建立。
- 歷史回放只證明時間順序與狀態密度，不證明可獲利。

## RC 驗證結論

- schema v7／state v5 能保存決策鏈且不改固定九欄。
- 2026/8 日盤 20 sessions、5,991 根 K 已完成 n=2／n=3 因果比較；保留 n=2。
- 三輪隔離 Shadow 通過；平均約 80.1 秒，TG dry-run。
- 仍需至少五個完整交易日前向 Shadow，特別驗證非空開盤證據、主鏡頭切換、A／B／C 與時間／動機失效生命週期。
