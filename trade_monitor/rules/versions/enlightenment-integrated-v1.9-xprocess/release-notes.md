# v1.9 X 流程整合正式版

本版由已驗證的 `enlightenment-integrated-v1.9-xprocess-rc-shadow` 升級，完整承接 v1.8；X 課程不是另一套策略，而是同一市場狀態中的盤中決策順序。

## 正式納入

- `decision_chain_context` state v1：因果保存開盤證據、第一次 DH／DL 樣本、已確認腳數、唯一主鏡頭、家族 DNA、三項共振、原四型態映射、質性 A／B／C、預期行為與時間／動機失效。
- schema v7、contract v7、market structure state v5，以及 v4→v5 的空 X 狀態安全遷移。
- X 流程與既有定錨、四象限、號盤、道氏防線、左右戰法、太極／一之、工作看法整合為單一路徑。

## 保留不變

- 原四型態、原九欄、一口單、收盤確認、結構停損、交易憲法、canonical message、Telegram 雙模式、Chrome DETAIL／OVERVIEW 與 resume guard。
- 多空鏡像；沒有每日三次硬上限。
- 同一 Automation `1-k`、原 RRULE、目標對話及通知政策。

## 未納入

- 第五種型態、獨立 X 投票答案、第十個通知欄位。
- 沒有來源的現貨價、固定點數跳空門檻、精確課程勝率、五檔委託簿推測。
- 無停損、攤平、放寬停損、滿倉、多口母子單及未完成反擊規則。

## 已知限制

原 RC 建議再完成五個交易日前向 Shadow；本門檻尚未完成。使用者於 2026-09-02 明確要求正式升級，因此本版在完整回放、三輪隔離 Shadow 與 197 項測試通過後升級，並保留此限制供後續前向觀察。
