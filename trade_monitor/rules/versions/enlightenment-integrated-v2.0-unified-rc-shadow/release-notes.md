# v2.0 統一交易系統候選版說明

## 規則整合

- 少於兩個已確認腳時只使用開盤證據、道氏與定錨。
- 兩腳以上依當時結構清晰度選太極或四象限為唯一主判讀工具，不再規定四象限必須等到四腳。
- 此規則受候選版明確功能開關保護；現行正式 v1.9 設定維持關閉。
- 四象限以定錨後的趨勢性與波動相對變化為主要標準；均線、五分 K、開盤區間與平均真實波幅只作交叉驗證。
- 至少三腳且太極與四象限有獨立、同向、相同失效條件時，才可共同確認。
- 盤中結構機會與可執行候選分開：被風險、障礙、追價或交易憲法否決的機會仍保留原因，不能被誤記成「沒有機會」。

## 中文顯示

- 內部 schema 與持久狀態代碼不變，避免破壞歷史相容與去重。
- Codex 與 Telegram 共用的固定 renderer 新增中文顯示層；形成中、待觸發、積極確認、保守確認、已失效、不宜追價等狀態不再外洩英文代碼。
- 第一類反轉＝小級警告且大級防線未破；第二類反轉＝原防線先破且反向延續確認；第三類反轉／跨級急轉＝同一段推進穿越小級與大級防線。

## 資料精度

- 新增可選唯讀結構化一分 K 介面與格式、時間、商品、開高低收、過期／未來資料的 fail-safe 驗證。
- 介面預設關閉；目前尚未配置真實即時來源，因此正式監控仍使用原圖面估計紀律。

## 部署狀態

- 本版是 RC Shadow 候選，未部署至 Automation `1-k`。
- 正式 active version 仍為 `enlightenment-integrated-v1.9-xprocess`，Automation 保持 `PAUSED`。
