# v2.1 前瞻全戰法整合版

## 核心修正

- 原四型態保留為一個戰法家族，不再是所有課程戰法必須映射的唯一出口。
- 每輪完整判讀開盤／號盤／箱型、樞紐／道氏／左右、定錨／四象限、太極、一之及整合決策流程，再收斂成唯一主情境、備用情境與主控戰法。
- 四象限、箱型、道氏／左右、太極、一之及原四型態都可成為主控戰法；進場、停損、應有行為、時間失效與出場使用該戰法自己的規則。
- 同一市場事件即使同時符合多套戰法，也只能選一套主控，其餘只列支持或衝突證據，不重複建立候選或模擬成交。

## 前瞻狀態

- 新增主要／備用情境的「潛在演化、增強、接近確認、確認、降級、取消」因果狀態。
- 每輪同時維護偏多與偏空預案，包含觀察區、K 棒行為、已收盤觸發、下一根評估、同級停損、第一障礙、不追價、等待根數、動機失效、退出與看法切換。
- 新增主控戰法、執行方式與選用理由；X 的啄木鳥、一回合與標準結構／動能快速失效被視為執行方式，不冒充盤勢型態。

## 太極演化

- 保存作用中段落、最近複製與修正結果、複製幅度／時間演化、修正幅度／時間演化及綜合評估。
- 複製越短、越慢而修正越深、越久時，原方向先降級並停止追價；複製失敗不直接反手，仍須反向錨與新回合確認。
- `prospective_context.taiji_evolution` 必須與 `cclass_context` 留存的因果段序一致，不能事後重畫。

## 輸出與相容性

- 使用者可見通知仍是固定九欄；Codex 與 Telegram 使用同一份標準訊息。
- schema 升至 v8、contract 升至 8、market structure state 升至 6。
- 內部欄位 `mapped_pattern` 為相容歷史名稱；v8 起其語意為「選定戰法」，可使用完整戰法目錄，不限四型態。
- 不改一口單、禁止攤平、結構停損、冷卻與事件去重原則。

## 尚有限制

- 本版尚未完成新的逐 K 多日因果回放與隔離前向觀察，不能由程式測試推論可穩定獲利。
- 結構化一分 K 行情仍預設關閉；無可靠數值來源時，點位必須維持圖面估計或明示無法可靠估計。
