# v2.1.2 高低點術語修正版

本版本完整承接 `enlightenment-integrated-v2.1.1-course-terms`，只修正使用者可見術語：

- 「較低高點／較低的高點」統一顯示為「次高點」。
- 「較高低點／較高的低點」統一顯示為「次低點」。
- 正式提示詞與共同 presentation layer 同時落實，因此 Codex 與 Telegram 使用相同說法。

本版未修改：

- 內部 Dow lower-high／higher-low 判斷及所有交易條件。
- 趨勢、定錨、樞紐、防線、太極、四象限與各戰法判斷規則。
- 進場、停損、出場、交易憲法與持久狀態轉移。
- v8 schema、contract v8、state v6、Chrome 雙視角及本機第 05 秒排程。
- Automation ID、RRULE、target task、通知設定與 PAUSED 狀態。

本版是 presentation-only 小版本，不聲稱提高獲利能力，也不重新執行歷史獲利回測或多日即時 Shadow。
