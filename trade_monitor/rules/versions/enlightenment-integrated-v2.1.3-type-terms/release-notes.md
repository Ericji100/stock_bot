# v2.1.3 Type 術語修正版

本版本完整承接 `enlightenment-integrated-v2.1.2-pivot-terms`，只修正使用者可見術語：

- 「第一類反轉／第二類反轉／第三類反轉」改回課程原名 `Type1／Type2／Type3`。
- 同一則通知中，各 Type 第一次出現時附固定簡短說明；同一 Type 後續只保留代號。
- 正式提示詞與共同 presentation layer 同時落實，因此 Codex 與 Telegram 使用相同說法。

本版未修改：

- 內部 `TYPE_1／TYPE_2／TYPE_3` 狀態及所有反轉判斷條件。
- 趨勢、定錨、樞紐、防線、太極、四象限與各戰法判斷規則。
- 進場、停損、出場、交易憲法與持久狀態轉移。
- v8 schema、contract v8、state v6、九欄、Chrome 雙視角及本機第 05 秒排程。
- Automation ID、RRULE、target task、通知設定與 PAUSED 狀態。

本版是 presentation-only 小版本，不聲稱提高獲利能力，也不重新執行歷史獲利回測或多日即時 Shadow。
