# v2.1.4 工作象限同級證據修正

本版本完整承接 `enlightenment-integrated-v2.1.3-schema-hotfix`，只修正工作象限把不同級數證據混用的問題：

- 工作象限的趨勢軸與波動軸必須來自同一控制級數、同一作用中錨後的波段。
- 小級控制時，以 DETAIL 最近約 5～20 分鐘判斷工作象限；大級或較早的高波動只保留為背景。
- 增加象限軸一致性驗證：趨勢增強時不得列第二／第三象限，趨勢降低時不得列第一／第四象限；波動軸亦採對稱約束。
- 通知分開表達大級背景與目前工作象限。

本版不修改進出場、停損、交易憲法、九欄格式、Telegram canonical message、Chrome 安全邊界或排程頻率。
