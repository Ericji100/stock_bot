# v2.1.5 道氏防線一致性修正

本版本完整承接 `enlightenment-integrated-v2.1.4-same-grade-quadrant`，修正「已辨識多波攻擊與道氏方向，但樞紐與防線仍為空」的矛盾：

- 開始、恢復、處理缺口或前次遺漏時，必須從當前可見圖面復原已完成的歷史樞紐因果。
- 復原的樞紐保留歷史 `bar_time`，但首次看見與確認時間只能從當前輪開始，不追認歷史成交。
- `dow_state_small`／`dow_state_large` 確認多空方向時，強制要求同級 ACTIVE 防線與 `PAIRED_CONFIRMED` 來源樞紐。
- 防線必須引用正確的攻擊樞紐：空頭對應高點，多頭對應低點，價位記錄不得互相矛盾。
- 價位精確度不再影響結構存在性；無法校準時使用 null，不得清空可驗證的防線。
- 固定 renderer 從通過驗證的結構狀態加入大／小級作用中防線摘要，避免通知文字遺漏。

本版不改變交易進出場、停損、交易憲法、九欄格式、Telegram canonical message、Chrome 安全邊界、排程頻率或原有同級象限修正。
