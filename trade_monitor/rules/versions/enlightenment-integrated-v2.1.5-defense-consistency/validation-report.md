# v2.1.5 道氏防線一致性驗證

- 定向測試：68 passed。
- 完整監控測試：263 passed。
- 回歸條件：小級道氏狀態為空方時，必須同時有作用中小級空頭防線及已配對樞紐高點；多方與大級完全鏡像。
- 因果復原：可在當前輪建檔過去 `bar_time` 的可見樞紐，但 `first_seen_at`、`locally_confirmed_at`、`paired_confirmed_at` 不得早於當前輪。
- 通知：固定九欄 renderer 可顯示通過驗證的作用中防線，不增加第十欄。
- 限制：仍是截圖判讀，點位可能只能圖面估計；本修正不代表獲利保證，也未新增結構化 OHLCV。
