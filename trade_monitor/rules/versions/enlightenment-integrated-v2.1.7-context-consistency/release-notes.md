# v2.1.7 太極、象限與情境一致性修正

本版本完整承接 `enlightenment-integrated-v2.1.6-anchor-hierarchy`，修正 2026-09-03 11:47～11:50 實盤通知所暴露的跨模組矛盾：

- 第一次啟動或恢復時必須重建目前仍有效的可見歷史太極段落；「不回填」只禁止追認歷史通知、交易及首次知悉時間。
- 已確認作用中大錨至少要保留對應太極定錨段；能辨識修正／複製時不得回報「尚無完整複製／修正」。
- 已確認作用中大錨不可被降為盤整：大級多方錨對應強勢偏多／偏多但回檔，大級空方錨完全鏡像。
- 趨勢性改以目前控制錨的方向衡量。大多方背景中的小級空方持續推進，代表小級空方趨勢性增加；低波動時應判向下第四象限，而不是第三象限。
- 主要與次要象限候選只可相差一個軸，避免第四象限直接把第二象限列為相鄰備選。
- 大小錨方向衝突時，主要與備用情境必須剛好涵蓋原大錨回檔／反彈與反向小錨延續兩條路徑。
- 內部 `SETUP_EVALUATION` 固定顯示為「盤中交易機會持續掃描」。
- 位置說明在可校準價軸時必須給現價區、上方壓力、下方支撐／防線及可否執行，不再只寫抽象「介於／靠近」。

本版不改變進出場戰法、停損、交易憲法、九欄順序、Telegram canonical message、Chrome 安全邊界或本機讀秒頻率。
