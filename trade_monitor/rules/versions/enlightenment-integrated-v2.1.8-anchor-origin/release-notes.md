# v2.1.8 大錨原始發動點一致性修正

本版本完整承接 `enlightenment-integrated-v2.1.7-context-consistency`，修正正式畫面驗證發現的最後一項級數錯配：10:00 低點至 11:21 高點是完整父級反轉推進，10:42 只能是內部子級起點，不能取代父級大錨起點。

- 跨級大錨若由同一方向推進使前一反向錨失效，並完成時段極值、重要結構、大級防線或 Type3 跨級破壞，必須承接前一反向錨的最後極值。
- 不得把既有小錨直接升級後沿用其中途起點，因而遺漏完整反轉的前半段。
- `taiji_context.anchor_id` 指向作用中大錨時，太極 `ANCHOR_1` 必須與大錨使用相同起點。
- 發現既有作用中錨起點錯誤時，保留不可變歷史：舊錨標為 `REPLACED`，本輪以正確起點建立新錨，不回填首次知悉時間。
- 跨分鐘語意與生命週期驗證提前到 Codex 重試階段，避免分析表面完成後才在 finalize 退化成資料不足通知。
- 已終止的同方向暫代防線可在其槽位建立新實例；ACTIVE 舊防線仍必須先終止。
- 只有舊大錨明確被正確大錨取代，或同輪完成可驗證的「歷史錨修復 → 反向大錨接管」時，才允許重建太極朝代；一般作用中太極段仍禁止無故消失。
- 單一 setup 槽採兩階段切換：先終止舊 setup，下一輪才建立新 setup。
- 多空完全鏡像。

本版不改變進出場戰法、停損、交易憲法、九欄順序、Telegram canonical message、Chrome 安全邊界、本機讀秒頻率或 240 秒分析保護上限。
