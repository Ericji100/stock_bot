# AI-HYBRID v32

此版本是隔離的歷史回放實驗，不接入正式監控。

- 程式擁有：已揭露1分K、指標、因果樞紐與事件、可引用結構候選、候選setup、成交順序、硬停損、成本與風控。
- AI擁有：定錨資格、大小級結構、象限、太極／一之／左右／道氏／X流程、情境權重、主控戰法、候選取捨、進場、持倉管理與主動出場。
- AI不得發明程式證據不存在的價格、時間、setup或成交；ENTRY_ELIGIBLE時只能進場或使用固定否決原因。
- 停損後的再進必須來自停損後新形成的客觀結構，不得重用舊交叉訊號。
- 這個版本不修改`trade_monitor`正式規則，也不修改Telegram Bot既有指令或排程。

所有績效必須以manifest中的規則、執行、提示詞、資料與模型指紋為準；不同版本不得混算。
