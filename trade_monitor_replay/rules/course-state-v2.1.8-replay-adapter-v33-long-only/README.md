# AI-HYBRID v33 LONG_ONLY

此版本是隔離的歷史回放實驗，不接入正式監控；v32雙向版保留作比較基準。

- 市場判讀維持雙向：空方定錨、道氏、象限、太極、一之與情境權重仍須完整辨識。
- 交易執行固定只做多或空手：不得建立空方setup、準備、進場、再進場或持倉。
- 空方證據只用於多方降級、停損／出場、禁止做多及等待多方重新取得資格。
- 程式候選篩選、AI提示詞及語意驗證器共同執行方向限制；不能只靠模型遵守文字要求。
- v32的正式課程判讀rubric、因果資料、下一根成交、硬停損、成本與風控守門均沿用，避免同時改變多個實驗變因。

這個版本不修改`trade_monitor`正式規則，也不修改Telegram Bot既有指令或排程。績效只能與相同manifest、執行版本、資料與模型指紋的結果比較。
